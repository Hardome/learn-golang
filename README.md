# Урок 003. Типы в Go

Тип определяет, какие значения может хранить переменная и какие операции над ними доступны. Go определяет тип
на этапе компиляции. В объявлении `var count int` тип указан явно, а в `count := 127` Go выводит его из литерала.

## Основные типы

| Типы | Что хранят | Нулевое значение |
| --- | --- | --- |
| `int8`, `int16`, `int32`, `int64` | Целые со знаком. Например, у `int8` диапазон от −128 до 127 | `0` |
| `uint8`, `uint16`, `uint32`, `uint64` | Целые без знака. Например, у `uint8` диапазон от 0 до 255 | `0` |
| `int`, `uint` | Целые шириной 32 или 64 бита, в зависимости от реализации | `0` |
| `float32`, `float64` | Числа с плавающей точкой. У `float64` выше точность | `0` |
| `complex64`, `complex128` | Комплексные числа с частями типа `float32` или `float64` | `0 + 0i` |
| `string` | Неизменяемые последовательности байтов | `""` |
| `bool` | Значения `true` и `false` | `false` |

Для форматов данных с фиксированной шириной используют типы вроде `uint32`. У `uintptr` другая задача.
Этот беззнаковый тип способен вместить биты значения указателя.

`byte` — псевдоним `uint8`. `rune` — псевдоним `int32`, который обычно обозначает кодовую точку Unicode.
Символ `'Ж'` задаёт кодовую точку `U+0416`. У строки `"Привет"` длина `len("Привет")` равна `12` байтам.
Связь байтов и кодовых точек разобрана в [уроке 028][strings].

## Вывод типа

Когда объявление выводит тип из нетипизированной константы, Go использует её тип по умолчанию.

| Объявление | Тип переменной |
| --- | --- |
| `count := 127` | `int` |
| `price := 32.32` | `float64` |
| `value := 2 + 3i` | `complex128` |
| `letter := 'Ж'` | `rune` (`int32`) |
| `label := "Привет"` | `string` |
| `isReady := true` | `bool` |

Можно указать нужный тип явно, например `var fraction float32 = 0.5`. Формат `%T` в `fmt.Printf` выводит тип, `%v` —
значение, а `%q` показывает строку в кавычках. Для `byte` и `rune` формат `%T` выводит `uint8` и `int32`, поскольку это
альтернативные имена тех же типов.

## Идентичность типов

Объявление `type cents int` создаёт отдельный тип с базовым типом `int`. Объявление `type amount = int`
даёт существующему типу `int` ещё одно имя. В выражении ниже `stored` и `unit` имеют разные типы,
поэтому перед сложением `stored` явно преобразуется в `int`.

```go
type cents int
type amount = int
var stored cents = 25
var unit amount = 5
fmt.Println(int(stored) + unit) // 30
```

Подробнее идентичность и псевдонимы разобраны в [уроке 017][aliases].

## Преобразования

Преобразование создаёт значение целевого типа. Порядок имеет значение, если операция уже потеряла информацию.
При целочисленном делении дробная часть отбрасывается. Преобразование результата сохраняет только полученное целое.

```go
count := 127
fmt.Println(count / 2)          // 63, целая часть результата.
fmt.Println(float64(count) / 2) // 63.5, деление чисел с плавающей точкой.
fmt.Println(float64(count / 2)) // 63, дробная часть уже отброшена.
```

При преобразовании целочисленной переменной в более узкий тип сохраняются младшие биты.
При преобразовании константы компилятор проверяет, помещается ли её точное значение в новый тип.

```go
number := 256
fmt.Println(uint8(number)) // 0, младшие восемь бит числа 256 равны нулю.
// _ = uint8(256)          // Ошибка компиляции. Константа выходит за диапазон uint8.
```
