# Урок 003. Типы в Go

В [hello.go](hello.go) собраны примеры основных встроенных типов. Go статически типизирован: тип каждой переменной известен на этапе компиляции. Даже в записи `count := 127` у `count` есть конкретный тип `int`, который Go выводит из литерала.

## Основные типы

| Типы | Что хранят | Нулевое значение |
| --- | --- | --- |
| `int8`, `int16`, `int32`, `int64` | Целые числа со знаком. Например, диапазон `int8` от −128 до 127. | `0` |
| `uint8`, `uint16`, `uint32`, `uint64` | Целые числа без знака. Например, диапазон `uint8` от 0 до 255. | `0` |
| `int`, `uint` | Целые числа размером 32 или 64 бита в зависимости от архитектуры. | `0` |
| `float32`, `float64` | Числа с плавающей точкой. `float64` даёт более высокую точность. | `0` |
| `complex64`, `complex128` | Комплексные числа. Действительная и мнимая части имеют тип `float32` или `float64` соответственно. | `0 + 0i` |
| `string` | Строки. Строковый литерал `"Привет"` записан в UTF-8 и занимает 12 байт. | `""` |
| `bool` | Логические значения `true` и `false`. | `false` |

`byte` — другое имя для `uint8`, а `rune` — для `int32`. Тип `rune` используют для кодовых точек Unicode. Например, `'Ж'` — одна кодовая точка `U+0416`, которая в UTF-8 занимает два байта. `len("Привет")` возвращает число байтов, то есть `12`.

## Вывод типа и преобразования

| Объявление | Тип переменной |
| --- | --- |
| `count := 127` | `int` |
| `price := 32.32` | `float64` |
| `value := 2 + 3i` | `complex128` |
| `letter := 'Ж'` | `rune` (`int32`) |
| `label := "Привет"` | `string` |
| `isReady := true` | `bool` |

Можно указать нужный тип явно, например `var fraction float32 = 0.5`. Формат `%T` в `fmt.Printf` выводит тип, `%v` — значение, а `%q` показывает строку в кавычках. Для `byte` и `rune` формат `%T` выводит `uint8` и `int32`, поскольку это альтернативные имена тех же типов.

Запись `float64(count)` преобразует значение `count` в `float64`. При `count := 127` выражение `count / 2` даёт целое `63`, а `float64(count) / 2` даёт `63.5`. Преобразование `float64(count / 2)` тоже допустимо, но деление там уже выполнено с целыми числами и результат равен `63`.

## Запуск

Выполните `go run hello.go` из каталога урока. Ожидаемый вывод приведён ниже.

```text
count: int = 127
price: float64 = 32.32
label: string = "Привет" (bytes: 12)
isReady: bool = true
signed: int8 = -128
octet: uint8 = 255
letter: int32 = Ж (U+0416)
fraction: float32 = 0.5
smallComplex: complex64 = (2+3i)
largeComplex: complex128 = (2+3i)
count / 2 = 63, float64(count) / 2 = 63.5
zero values: 0, "", false
```
