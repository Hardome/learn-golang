# Урок 009. Массивы в Go

Массив хранит фиксированное число элементов одного типа. К каждому элементу обращаются по его позиции, или индексу.

## Тип и длина

Длина входит в тип массива. Поэтому `[5]int` и `[4]int` — разные типы.

Длина массива должна быть неотрицательной константой, представимой типом `int`.

Массив `[0]int{}` допустим. Его длина и ёмкость равны нулю.

Многомерный массив состоит из вложенных массивов. Например, `[2][3]int` содержит два элемента типа `[3]int`.

## Объявление и заполнение

| Запись | Что получается |
| --- | --- |
| `var numbers [5]int` | Пять нулей. Каждый элемент получает нулевое значение своего типа. |
| `[5]int{1, 2, 3, 4, 5}` | Пять заданных целых чисел. |
| `[5]int{1}` | Массив `[1 0 0 0 0]`. Пропущенные элементы получают нулевые значения. |
| `[...]int{1}` | Массив типа `[1]int` с единственным элементом. |
| `[...]int{3: 7}` | Массив типа `[4]int`. Значение `7` находится по индексу `3`, длина равна `4`. |

В непустом литерале с `[...]` длина равна наибольшему индексу элемента плюс один.

Если ни один индекс не указан явно, элементы идут подряд с нулевой позиции. Например, `[...]int{2, 4, 6}` имеет тип
`[3]int`.

## Индексы

Для примеров индексирования используем `values := [5]int{1, 2, 3, 4, 5}`.

`len(values)` возвращает число элементов.

Для массива длины `5` допустимы индексы от `0` до `4`.

`values[0]` читает первый элемент, а `values[len(values)-1]` — последний элемент непустого массива.

Запись `values[0] = 99` меняет первый элемент.

Константный индекс за пределами массива вызывает ошибку компиляции.

Индекс, вычисленный во время выполнения, при выходе за границы вызывает `panic`.

## Сравнение

Массивы одного типа можно сравнить через `==`, если их тип элемента сравним. Это правило действует и для массивов
нулевой длины. Например, `[0]int` сравним, а `[0][]int` — нет.

Массивы равны, когда совпадают элементы на всех позициях. Например, `[4]int{3, 4, 5}` и `[4]int{3, 4, 5, 0}` равны,
поскольку пропущенный элемент получает значение `0`.

Вложенные массивы сравниваются рекурсивно по своим элементам.

## Копирование массива

При присваивании копируются все элементы массива. После `copied := values` запись `copied[0] = 99` меняет первый элемент
копии, а в `values[0]` по-прежнему хранится `1`.

Передача массива в функцию по значению тоже копирует его элементы.

При копировании массива указателей копируются сами указатели. Они продолжают указывать на те же объекты.

Если функции нужно менять элементы исходного массива, передайте указатель на массив или срез.

## Срез на основе массива

У адресуемого массива выражение `values[:]` создаёт срез с общим хранилищем. Изменение элемента среза видно через
массив.

## Перебор через `range`

Цикл `for index, value := range values` даёт индекс и значение каждого элемента.

В `for _, value := range values` пустой идентификатор `_` пропускает индекс. Такой цикл подходит для суммирования
элементов, когда нужны только их значения.

При переборе массива с двумя переменными итерации `range` использует копию значения массива, полученную перед циклом.

```go
sample := [3]int{1, 2, 3}
sum := 0
for index, value := range sample {
    if index == 0 {
        sample[1] = 20
    }
    sum += value
}
```

Запись меняет `sample[1]` на `20`, а `sum` остаётся суммой исходных элементов: `1 + 2 + 3`.

При переборе указателя на массив значения элементов читаются из исходного массива.
