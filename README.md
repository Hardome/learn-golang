# Урок 015. Рекурсивные функции в Go

Рекурсивная функция вызывает саму себя. В каждом вызове у неё свои параметры и локальные переменные.
Для завершения нужен **базовый случай**, который возвращает результат сразу. Каждый рекурсивный шаг должен
приближать задачу к этому случаю.

Примеры можно запустить из [hello.go](hello.go) командой `go run hello.go`.

## Факториал

Факториал `n!` — произведение целых чисел от 1 до `n`. По определению `0! = 1`.
На каждом шаге умножаем `n` на факториал предыдущего числа.

```go
func factorial(n uint) uint64 {
    if n < 2 {
        return 1
    }
    return uint64(n) * factorial(n-1)
}
```

У каждого вызова своё значение `n`. Пока следующий вызов выполняется, предыдущий ждёт результат,
чтобы умножить его на своё `n`.

```text
Вызовы:    factorial(3) → factorial(2) → factorial(1)
Результат:      6       ←      2       ←      1
```

`factorial(1)` возвращает `1` сразу, потому что выполняется базовый случай `n < 2`.
У `factorial(2)` и `factorial(3)` ещё остаётся по одному умножению. С каждым шагом `n` уменьшается на один,
так что и число вызовов, и максимальное число незавершённых вызовов имеют порядок `O(n)`.

```go
fmt.Println(factorial(0), factorial(5)) // 1 120
```

## Числа Фибоначчи

Первые два числа — `F(0) = 0` и `F(1) = 1`. Каждое следующее равно сумме двух предыдущих.

```go
func fibonacci(n uint) uint64 {
    if n < 2 {
        return uint64(n)
    }
    return fibonacci(n-1) + fibonacci(n-2)
}
```

У небазового вызова две подзадачи. При вычислении `F(4)` обе ветви заново вычисляют `F(2)`.

```text
F(4)
├─ F(3)
│  ├─ F(2)
│  │  ├─ F(1)
│  │  └─ F(0)
│  └─ F(1)
└─ F(2)
   ├─ F(1)
   └─ F(0)
```

Общее число вызовов растёт экспоненциально из-за повторов. Глубину стека определяет самая длинная
ветвь, поэтому она растёт линейно. Если вычислять числа по порядку в цикле, на каждом шаге достаточно
двух предыдущих результатов. Это даёт `O(n)` времени и `O(1)` дополнительной памяти.

```go
fmt.Println(fibonacci(0), fibonacci(1), fibonacci(6)) // 0 1 8
```

Оба примера принимают неотрицательный аргумент `uint`. В `uint64` помещаются значения до `20!` и `F(93)`
включительно. При переполнении результат вычисляется по модулю 2⁶⁴. Рекурсивный расчёт Фибоначчи становится
непрактичным задолго до этой границы. Если цепочка вызовов не достигает базового случая и стек горутины
превысит допустимый размер, Go завершит программу.
