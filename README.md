# Урок 007. Поразрядные операции в Go

Поразрядные операции обрабатывают биты целых чисел. При `&`, `|`, `^` и `&^` биты результата
вычисляются отдельно для каждой позиции. Сдвиг переносит биты на другие позиции.

В примерах `uint8` задаёт восемь битов. Формат `%08b` в `fmt.Printf` показывает эти позиции,
дополняя двоичную запись ведущими нулями.

## Операторы

Префикс `0b` обозначает двоичный литерал.

В таблице `a = 0b00001100` (12) и `b = 0b00001010` (10). Унарный `^a` инвертирует все восемь битов
`a`. Для операнда типа `int` ширина зависит от реализации.

| Выражение | Как определяется результат | Операнды и двоичный результат |
| --- | --- | --- |
| `a & b` | Бит равен 1, если у обоих операндов он равен 1. | `0b00001100`<br>`0b00001010`<br>**`0b00001000`** |
| `a \| b` | Бит равен 1, если хотя бы у одного он равен 1. | `0b00001100`<br>`0b00001010`<br>**`0b00001110`** |
| `a ^ b` | Бит равен 1, если биты операндов различаются. | `0b00001100`<br>`0b00001010`<br>**`0b00000110`** |
| `a &^ b` | Единицы в `b` сбрасывают те же биты в `a`. | `0b00001100`<br>`0b00001010`<br>**`0b00000100`** |
| `^a` | Каждый 0 меняется на 1, каждый 1 — на 0. | `0b00001100`<br>**`0b11110011`** |
| `a << 1` | Биты сдвигаются на одну позицию влево. | `0b00001100`<br>**`0b00011000`** |
| `a >> 1` | Биты сдвигаются на одну позицию вправо. | `0b00001100`<br>**`0b00000110`** |

## Сдвиги

- **Беззнаковые числа.** Освободившиеся при сдвиге позиции заполняются нулями.
- **Знаковые числа.** Сдвиг вправо заполняет старшие позиции знаковым битом, поэтому `int8(-7) >> 1` даёт `-4`.
  Деление `int8(-7) / 2` отбрасывает дробную часть в сторону нуля и даёт `-3`.
- **Тип результата.** Результат сдвига типизированного левого операнда сохраняет его тип.
- **Потеря старших битов.** При сдвиге влево биты, вышедшие за ширину типа, отбрасываются.
- **Сдвиг на ширину типа.** Счётчик может достигать ширины операнда и превышать её. Для `uint8` сдвиг влево или вправо
  на восемь позиций даёт ноль.
- **Счётчик сдвига.** Количество позиций должно быть целым и неотрицательным. Отрицательная константа недопустима.
  Отрицательный счётчик во время выполнения вызывает `panic`.

```go
var a uint8 = 0b00001100
width := uint(8)
fmt.Printf("%08b\n", a << width) // 00000000

// _ = a << -1 // Ошибка компиляции. Счётчик задан отрицательной константой.
// count := -1
// _ = a << count // Паника. Отрицательное значение счётчика получено во время выполнения.
```

## Маска флагов

Маска выделяет нужные разряды целого числа.

В этом примере каждый бит представляет право чтения, записи или выполнения.

```go
const (
    read    uint8 = 0b001
    write   uint8 = 0b010
    execute uint8 = 0b100
)
```

У `read`, `write` и `execute` по одному установленному биту. `&` оставляет только позиции,
отмеченные маской. `|` устанавливает позиции из маски, а `&^` очищает их.

```go
flags := read | execute
fmt.Printf("%08b\n", flags)       // 00000101
fmt.Println(flags & write != 0)  // false, бит записи пока равен 0.
flags = flags | write
fmt.Printf("%08b\n", flags)       // 00000111
flags = flags &^ execute
fmt.Printf("%08b\n", flags)       // 00000011
```

- **Хотя бы один флаг.** `flags&mask != 0` проверяет наличие хотя бы одного бита из маски. Для пустой маски результат
  всегда `false`.
- **Все флаги.** `flags&mask == mask` проверяет наличие всех битов из маски. Для пустой маски результат всегда `true`.

## Приоритет операторов

- `&`, `&^`, `<<` и `>>` имеют приоритет умножения.
- `|` и бинарный `^` имеют приоритет сложения.

Скобки помогают явно показать порядок вычислений в выражениях с масками и сдвигами.
