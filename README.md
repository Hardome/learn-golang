# Урок 006. Условные выражения в Go

Условное выражение отвечает на вопрос, истинно ли условие: его значение равно `true` или `false`. Сравнения и логические
операторы позволяют составлять такие выражения.

Результат сравнения — нетипизированное логическое значение. В записи `matches := 7 == 2` переменная `matches` получает
тип `bool`.

## Сравнения

| Оператор | Проверка | Пример | Результат |
| --- | --- | --- | --- |
| `==` | Равенство | `7 == 2` | `false` |
| `!=` | Неравенство | `7 != 2` | `true` |
| `<` | Строго меньше | `7 < 2` | `false` |
| `<=` | Меньше или равно | `7 <= 7` | `true` |
| `>` | Строго больше | `7 > 2` | `true` |
| `>=` | Больше или равно | `2 >= 7` | `false` |

### Совместимость операндов

При любом сравнении хотя бы один операнд должен быть присваиваем типу другого. Например, для переменных `a` типа `int`
и `b` типа `int64` нужно явное преобразование, как в `int64(a) == b`.

## Сравнимость по типам

Для `==` и `!=` операнды должны быть сравнимы. Особый случай — сравнение среза, карты или функции с `nil`.

### Целые числа

Целочисленные типы поддерживают `==`, `!=` и все четыре оператора порядка (`<`, `<=`, `>`, `>=`).

### Числа с плавающей точкой

Типы `float32` и `float64` поддерживают равенство и сравнение по порядку по правилам IEEE 754.

`NaN` не равен самому себе. Для проверки используют `math.IsNaN`.

### Комплексные числа

Типы `complex64` и `complex128` поддерживают `==` и `!=`. Равенство проверяется по действительной и мнимой частям.

### Логические значения

Для `bool` доступны только `==` и `!=`.

### Строки

Строки поддерживают равенство и сравниваются по порядку лексикографически по байтам.

### Массивы

Массив сравним, если сравним тип его элементов. При проверке равенства Go сравнивает элементы с одинаковыми индексами.

### Структуры

Структура сравнима, если сравнимы типы всех её полей. При проверке равенства Go сравнивает соответствующие поля с
именами, отличными от `_`.

### Указатели

Указатели равны, если указывают на одну переменную или оба равны `nil`. Указатели на разные переменные нулевого размера
могут быть равны.

### Каналы

Каналы равны, если получены из одного и того же вызова `make` или оба равны `nil`.

### Интерфейсы

Два интерфейсных значения равны, если оба равны `nil` или их динамические типы совпадают и динамические значения равны.

Интерфейс с динамическим типом `*int` и значением `nil` не равен `nil`.

Сравнение интерфейсов с одинаковым несравнимым динамическим типом вызывает `panic`. Пример — два значения `any`, каждое
из которых содержит `[]int`. То же правило действует для интерфейсных элементов массивов и полей структур.

### Срезы

Срез можно сравнить через `==` или `!=` только с `nil`.

### Карты

Карту можно сравнить через `==` или `!=` только с `nil`.

### Функции

Значение функции можно сравнить через `==` или `!=` только с `nil`.

## Логические операторы

| Оператор | Когда выражение истинно |
| --- | --- |
| `a && b` | Оба условия истинны. |
| `a || b` | Хотя бы одно условие истинно. |
| `!a` | Условие `a` ложно. |

Среди логических операторов самый высокий приоритет у `!`, затем идёт `&&`, затем `||`. Скобки помогают явно показать,
какие проверки составляют одно условие.

Операторы `&&` и `||` вычисляют левую часть первой. Если она уже определяет результат, правая часть пропускается. Для
`&&` это происходит при `false`, для `||` — при `true`. Поэтому выражение `divisor != 0 && a/divisor > 2` безопасно и
при нулевом делителе, если `divisor` — переменная.

## Проверка диапазона

Чтобы проверить, что значение строго между двумя границами, соедините два сравнения через `&&`.

```go
low < value && value < high
```

Цепочка `low < value < high` недопустима. Результат первого сравнения логический, поэтому его нельзя сравнить через `<`
с верхней границей.

## Условие в `if`

`if` выполняет первый блок при `true`, а блок `else` — при `false`.

```go
isAdult, hasTicket := true, false
var message string

if isAdult && hasTicket {
    message = "Вход открыт"
} else {
    message = "Вход закрыт"
}
```

Для входа нужны оба условия. Здесь `hasTicket` равно `false`, поэтому выполняется `else` и меняется `message`.
