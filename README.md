# Урок 011. Циклы в Go

Цикл повторяет блок кода. В [hello.go](hello.go) показано, как выполнить заданное число итераций, повторять действия по условию и перебрать элементы массива.

## Формы `for`

| Запись | Как работает |
| --- | --- |
| `for i := 1; i <= 4; i++` | Объявляет счётчик один раз, проверяет условие перед каждой итерацией и увеличивает счётчик после неё. |
| `for power < 10` | Проверяет условие перед каждой итерацией. В примере значение `power` удваивается внутри цикла. |
| `for { ... }` | Повторяет тело без проверки условия. В примере цикл завершается через `break` после третьей итерации. |
| `for index, value := range numbers` | Перебирает массив, возвращая индекс и значение каждого элемента. |

В цикле со счётчиком `i <= 4` включает число `4`. Условие `i < 4` завершило бы цикл до этой итерации. Если проверка ложна уже перед первым проходом, тело цикла с условием не выполнится ни разу.

## `break` и `continue`

В примерах `break` завершает ближайший цикл, а `continue` пропускает оставшуюся часть текущей итерации. Для цикла со счётчиком после `continue` выполняется шаг вроде `i++`. В цикле с `range` Go переходит к следующему элементу.

В массиве `[2 5 8 11]` проверка `number%2 != 0` пропускает `5` и `11`. Поэтому к сумме прибавляются только `2` и `8`. Запись `for _, number := range numbers` использует `_`, чтобы пропустить индекс.

## Запуск

Выполните `go run hello.go` из каталога урока. Ожидаемый вывод указан и в комментариях рядом с вызовами печати.

```text
Сумма от 1 до 4: 10
Первая степень двойки не меньше 10: 16
Количество попыток: 3
Сумма чётных элементов: 10
```
