# Урок 003. Типы в Go

Тип определяет, какие значения можно хранить и какие операции над ними доступны. Go статически типизирован: тип
переменной известен на этапе компиляции.

В объявлении `count := 127` Go выводит тип `int` из целочисленного литерала.

## Основные типы

- `int8`, `int16`, `int32`, `int64` — Целые числа со знаком. Например, диапазон `int8` от −128 до 127. Нулевое значение
  — `0`.
- `uint8`, `uint16`, `uint32`, `uint64` — Целые числа без знака. Например, диапазон `uint8` от 0 до 255. Нулевое
  значение — `0`.
- `int`, `uint` — Целые числа размером 32 или 64 бита в зависимости от архитектуры. Нулевое значение — `0`.
- `float32`, `float64` — Числа с плавающей точкой. `float64` даёт более высокую точность. Нулевое значение — `0`.
- `complex64`, `complex128` — Комплексные числа. Действительная и мнимая части имеют тип `float32` или `float64`
  соответственно. Нулевое значение — `0 + 0i`.
- `string` — Строки. Строковый литерал `"Привет"` записан в UTF-8 и занимает 12 байт. Нулевое значение — `""`.
- `bool` — Логические значения `true` и `false`. Нулевое значение — `false`.

`byte` — другое имя для `uint8`, а `rune` — для `int32`. Тип `rune` используют для кодовых точек Unicode. Например,
`'Ж'` — одна кодовая точка `U+0416`, которая в UTF-8 занимает два байта. `len("Привет")` возвращает число байтов, то
есть `12`.

## Вывод типа и преобразования

| Объявление | Тип переменной |
| --- | --- |
| `count := 127` | `int` |
| `price := 32.32` | `float64` |
| `value := 2 + 3i` | `complex128` |
| `letter := 'Ж'` | `rune` (`int32`) |
| `label := "Привет"` | `string` |
| `isReady := true` | `bool` |

Можно указать нужный тип явно, например `var fraction float32 = 0.5`. Формат `%T` в `fmt.Printf` выводит тип, `%v` —
значение, а `%q` показывает строку в кавычках. Для `byte` и `rune` формат `%T` выводит `uint8` и `int32`, поскольку это
альтернативные имена тех же типов.

Преобразование влияет на деление только тогда, когда оно выполнено до операции.

```go
count := 127
fmt.Println(count / 2)          // 63, целая часть результата.
fmt.Println(float64(count) / 2) // 63.5, деление чисел с плавающей точкой.
fmt.Println(float64(count / 2)) // 63, дробная часть уже отброшена.
```

## Идентичность типов и преобразования

- Объявление `type cents int` создаёт отдельный именованный тип с базовым типом `int`. `type amount = int` вводит
  псевдоним того же типа.
- Если `var stored cents = 25` и `var unit amount = 5`, для сложения нужно преобразование `int(stored) + unit`.
- `int` имеет размер 32 или 64 бита в зависимости от реализации. Для форматов данных и протоколов выбирайте тип с
  заданной шириной. `uintptr` — беззнаковый целочисленный тип, способный вместить биты значения указателя.
- При преобразовании целочисленной переменной в более узкий тип Go оставляет младшие биты.
  Для константы Go сначала проверяет, представимо ли значение в новом типе.

  ```go
  number := 256
  fmt.Println(uint8(number)) // 0, младшие восемь бит равны нулю.
  // _ = uint8(256)         // Ошибка: константа не помещается в uint8.
  ```
- Строка — неизменяемая последовательность байтов. `s[i]` возвращает байт, а `len(s)` — число байтов. Строка может
  содержать произвольные байты, включая невалидный UTF-8. При переборе `range` индексы являются смещениями в байтах, а
  неверная последовательность даёт `U+FFFD` с продвижением на один байт.
