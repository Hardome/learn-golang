# Урок 008. Операторы присваивания в Go

В [hello.go](hello.go) показано, как присвоить переменной новое значение, выполнить операцию с присваиванием и обменять значения двух переменных.

## Простое и множественное присваивание

`total := 10` объявляет переменную с начальным значением. После объявления запись `total = 12` меняет её значение.

При множественном присваивании правые выражения вычисляются до записи результатов. Поэтому две переменные можно обменять одной инструкцией.

```go
left, right := "лево", "право"
left, right = right, left
fmt.Println(left, right) // право лево
```

## Составное присваивание

Для обычной переменной `total += 3` равносильно `total = total + 3`. Составное присваивание вычисляет левый операнд один раз. Например, в `items[index()] += 1` функция `index()` будет вызвана один раз.

| Операторы | Действие |
| --- | --- |
| `+=`, `-=`, `*=`, `/=`, `%=` | Выполняют арифметическую операцию и сохраняют результат. |
| `&=`, `\|=`, `^=`, `&^=` | Выполняют поразрядную операцию и сохраняют результат. |
| `<<=`, `>>=` | Сдвигают биты влево или вправо и сохраняют результат. |

Тип переменной сохраняется. В примере `total` имеет тип `int`, поэтому при `total /= 4` значение `30` превращается в `7`.

## Порядок вычислений и допустимые операнды

- Множественное присваивание выполняется в две фазы. Сначала вычисляются правые выражения и операнды индексов и разыменований слева. Затем запись идёт слева направо. В `index, items[index] = 1, 99` элемент выбирается по старому значению `index`. При записи в одно и то же место последнее присваивание побеждает.
- Слева допускаются адресуемое выражение, индекс карты или `_` для отбрасывания значения. Индекс карты допускает присваивание, хотя взять адрес элемента через `&m[key]` нельзя. Запись в карту со значением `nil` вызывает `panic`.
- Типы справа подчиняются правилам присваиваемости. Нетипизированная константа должна быть представима типом получателя. Существующим переменным присваивают через `=`. Для `:=` действуют правила объявления, в том числе требование хотя бы одного нового имени в том же блоке.
- Если справа один вызов с несколькими результатами, слева нужно соответствующее число получателей. Для ненужного результата можно использовать `_`. Составное присваивание выполняется только для одного получателя и одного правого выражения.
