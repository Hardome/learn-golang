# Урок 002. Переменные в Go

Переменная хранит значение определённого типа. После объявления ей можно присвоить новое значение.

## Объявление и присваивание

Внутри функции можно объявить переменную с явным типом, вывести тип из значения или использовать `:=`.

```go
var name string        // Нулевое значение строки — "".
var greeting = "Go"    // Go выводит тип string.
language := "Golang"   // Краткое объявление внутри функции.
name = "Язык Go"       // Присваивание уже объявленной переменной.
fmt.Println(name, greeting, language) // Язык Go Go Golang
```

Имена чувствительны к регистру. Локальные `name` и `Name` — разные переменные, обе видны только в своих областях.

## Чем отличаются `var` и `:=`

| Возможность | `var` | `:=` |
| --- | --- | --- |
| Объявить переменную | На уровне пакета и внутри функций | Только внутри функций |
| Получить тип `int64` | `var count int64 = 1` | `count := int64(1)` |
| Обойтись без начального значения | Да, `var count int` даёт `0` | Справа обязательно указать значение или выражение |
| Повторно объявить имя в том же блоке | Ошибка | Допустимо вместе с новым именем |

Для простой локальной переменной с начальным значением обычно используют `:=`. Если нужно только обновить значение
существующей переменной, используйте `=`, например `count = 2`.

## Область видимости и пограничные случаи

- `var` работает на уровне пакета и внутри функций. Внутри блока имя локальной переменной становится видимым после
  объявления. `var value = value` во внутреннем блоке может взять начальное значение из внешней переменной с тем же
  именем.
- Краткое объявление `:=` требует хотя бы одного нового имени, отличного от `_`. Существующее имя из того же блока с тем
  же типом получает новое значение.

  ```go
  count := 1
  count, next := 2, 3                   // Обновили count и объявили next.
  fmt.Println(count, next)             // 2 3
  // count := 4                        // Ошибка: в том же блоке нет нового имени.
  ```
- Во вложенном блоке новое объявление может затенить внешнюю переменную. После окончания блока снова видно внешнее имя.
  При работе с `err` это важно: `:=` во вложенном блоке может создать отдельную переменную.
- Нулевое значение зависит от типа. Для указателей, срезов, карт, каналов, функций и интерфейсов это `nil`. Выражению
  `nil` нужен контекст типа: `var p *int = nil` допустимо, а `var p = nil` не компилируется. Используйте `_`, чтобы явно
  отбросить ненужное значение.
