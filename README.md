# Урок 008. Операторы присваивания в Go

Присваивание записывает значение, вычисленное справа, в получатель слева. За одну инструкцию можно обновить одну
переменную, несколько переменных или элемент коллекции.

## Простое присваивание

После объявления `total := 10` инструкция `total = 12` заменяет значение переменной на `12`.

`total := 10` — краткое объявление с начальным значением. Для `:=` хотя бы одно имя, отличное от `_`, должно быть новым
в текущем блоке.

## Множественное присваивание

Две переменные можно обменять одной инструкцией. Go вычисляет правую часть до записи, поэтому каждое из двух
выражений справа читает прежнее значение переменной.

```go
left, right := "лево", "право"
left, right = right, left
fmt.Println(left, right) // право лево
```

### Порядок вычислений

1. **Вычисление.** Go вычисляет выражения справа, а также операнды индексов и разыменований слева.
2. **Запись.** Go присваивает значения слева направо.

В следующем примере элемент массива выбирается по старому значению `index`.

```go
items := [2]int{10, 20}
index := 0
index, items[index] = 1, 99    // Для items[index] используется старый индекс 0.
fmt.Println(index, items)      // 1 [99 20]
```

После присваивания `index` равен `1`, а `items[0]` равен `99`.

Если несколько присваиваний записывают в одно и то же место, сохраняется последнее записанное значение.

### Результаты функции

Когда справа стоит один вызов функции с несколькими результатами, слева нужно столько же получателей.

## Составное присваивание

Для обычной переменной `total += 3` равносильно `total = total + 3`.

У составного присваивания один получатель и одно выражение справа. Получатель вычисляется один раз.
В примере `nextIndex` возвращает индекс `0` и увеличивает счётчик вызовов. Один и тот же элемент
используется для чтения и записи результата сложения.

```go
items := [2]int{10, 20}
calls := 0
nextIndex := func() int {
    calls++
    return 0
}
items[nextIndex()] += 5
fmt.Println(items, calls) // [15 20] 1
```

| Операторы | Действие |
| --- | --- |
| `+=`, `-=`, `*=`, `/=`, `%=` | Выполняют арифметическую операцию и сохраняют результат. |
| `&=`, `\|=`, `^=`, `&^=` | Выполняют поразрядную операцию и сохраняют результат. |
| `<<=`, `>>=` | Сдвигают биты влево или вправо и сохраняют результат. |

Составное присваивание сохраняет тип переменной.

При `total /= 4` для `total` типа `int` со значением `30` результат равен `7`, поскольку деление целочисленное.

## Допустимые получатели

- **Адресуемое выражение.** Например, переменная `total` или элемент массива `items[index]`.
- **Индекс карты.** Запись `m[key] = value` допустима, хотя взять адрес элемента через `&m[key]` нельзя.
- **Пустой идентификатор `_`.** В присваивании через `=` он отбрасывает соответствующее значение справа.

Запись в карту со значением `nil` вызывает панику. Правила записи и удаления разобраны в [уроке 021][maps].

## Присваиваемость

Значение справа должно быть присваиваемо типу получателя.

Нетипизированная константа должна быть представима в типе получателя.
