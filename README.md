# Урок 004. Константы в Go

Константа — значение, известное во время компиляции. Ключевое слово `const` связывает это значение с именем.
Константу объявляют сразу со значением. Попытка изменить это значение вызывает ошибку компиляции. Объявлять константы
можно как на уровне пакета, так и внутри функции.

## Объявление и тип

Константы бывают логическими, строковыми и числовыми. В `const appName string = "Go"` тип указан явно.
В `const retries = 3` тип опущен, поэтому `retries` остаётся нетипизированной целочисленной константой.
Go определяет конкретный тип при её использовании.

```go
const retries = 3
defaultRetries := retries
var retries8 uint8 = retries
var retries64 int64 = retries
const maxRetries uint8 = retries

fmt.Printf("%T %T %T\n", defaultRetries, retries8, retries64) // int uint8 int64
fmt.Printf("%T %d\n", maxRetries, maxRetries)                // uint8 3
// var invalid uint8 = 256 // Ошибка компиляции. Значение выходит за диапазон uint8.
```

В `:=` тип переменной выводится из константы. Для целочисленной константы тип по умолчанию — `int`.
При объявлении `var` с явным типом Go проверяет, представимо ли значение в этом типе. Число `3`
помещается и в `uint8`, и в `int64`. В `const maxRetries uint8` тип получает сама константа.

## Блок `const` и `iota`

В блоке `const (...)` первая строка объявления содержит выражение. Если ниже его опустить, Go повторит список выражений
и указанный тип из ближайшей предыдущей строки, где они были записаны. Поэтому `mediumLimit` получает `int(1)`, а
`maxLimit` — `int(3)`.

```go
const (
    smallLimit int = 1
    mediumLimit
    largeLimit int = 3
    maxLimit
)
```

`iota` — индекс спецификации внутри блока `const`. Каждая строка объявления в примере ниже содержит одну
спецификацию. Счёт начинается с `0`. Строка с `_` занимает позицию, а имена в одной спецификации
получают одно и то же значение `iota`. Выражение `1 << iota` сдвигает единичный бит влево.

```go
const (
    readMask               = 1 << iota            // Позиция 0. Значение 1.
    writeMask                                     // Позиция 1. Значение 2.
    _                                             // Позиция 2 пропущена.
    executeMask, auditMask = 1 << iota, 1 << iota  // Позиция 3. Оба значения равны 8.
)
fmt.Println(readMask, writeMask, executeMask, auditMask) // 1 2 8 8
```

У `writeMask` и `_` выражение унаследовано от `readMask`. При вычислении подставляется `iota` текущей
спецификации. В отдельном блоке счёт снова начнётся с нуля.

## Чем отличаются `const` и `var`

| Свойство | `const` | `var` |
| --- | --- | --- |
| Значение | Фиксируется при компиляции | Можно присвоить новое значение после объявления |
| Начальное значение | Требуется константное выражение | Допустим результат вызова функции |
| Если выражение опущено | В блоке повторяется предыдущее | Берётся нулевое значение указанного типа |
| Тип | Может быть типизированной или нетипизированной | Всегда имеет тип, явный или выведенный |
| Длина массива | Можно использовать целочисленную константу | Переменная в качестве длины массива вызовет ошибку |

Например, фиксированную длину массива можно задать константой, а число заполненных элементов хранить в переменной.

```go
const capacity = 3
var items [capacity]int
var count int // Начальное значение равно 0.

items[count] = 42
count++
// capacity++ // Ошибка компиляции: значение константы нельзя изменить.
```

## Константные выражения и пределы

- Числовые константы представляют точные значения произвольной точности в модели языка. Реализации могут ограничивать
  внутреннюю точность в пределах, указанных спецификацией. Пусть `const huge = 1 << 100`. Тогда `huge >> 98`
  равно `4` и представимо как `int` при передаче в `fmt.Println`. Объявление `var value int64 = huge` вызывает
  ошибку компиляции при проверке представимости итогового значения в `int64`.
- `len("Go")` — константа. Для массива или указателя на массив `len` и `cap` тоже могут быть константами, когда операнд
  не содержит приёмов из канала или неконстантных вызовов функций. `nil` и составные литералы вроде `[2]int{1, 2}` сами
  по себе константами не являются.
