# Урок 011. Циклы в Go

Цикл повторяет блок кода. В Go для этого используют `for`: со счётчиком, с условием, без условия или с перебором
через `range`.

## Формы `for`

- `for i := 1; i <= 4; i++` — Задаёт начальное значение счётчика, проверяет условие перед каждой итерацией и
  выполняет шаг `i++` после неё.
- `for power < 10` — Повторяет тело, пока условие истинно. Условие проверяется перед каждой итерацией.
- `for { ... }` — Повторяет тело без проверки условия.
- `for index, value := range numbers` — Перебирает массив, возвращая индекс и значение каждого элемента.

```go
sum := 0
for i := 1; i <= 4; i++ {
    sum += i
}
```

Условие `i <= 4` включает итерацию с `i == 4`. Условие `i < 4` завершило бы цикл до неё.

Если условие ложно при первой проверке, тело цикла не выполняется ни разу.

Например, при `power := 1` цикл `for power < 10` с шагом `power *= 2` остановится, когда `power` достигнет `16`.

## `break` и `continue`

### `break`

В следующем примере `break` завершает ближайший цикл, когда счётчик достигает трёх.

```go
attempts := 0
for {
    attempts++
    if attempts == 3 {
        break
    }
}
```

`break label` завершает внешний цикл с указанной меткой.

### `continue`

`continue` пропускает оставшуюся часть текущей итерации.

```go
numbers := [...]int{2, 5, 8, 11}
evenSum := 0
for _, number := range numbers {
    if number%2 != 0 {
        continue
    }
    evenSum += number
}
```

Проверка `number%2 != 0` пропускает нечётные `5` и `11`. К сумме прибавляются `2` и `8`.

В цикле со счётчиком после `continue` выполняется шаг вроде `i++`.

В цикле с `range` после `continue` Go переходит к следующему элементу.

`continue label` переходит к следующей итерации внешнего цикла с указанной меткой.

## Перебор через `range`

Тип выражения справа от `range` определяет, какие значения получит тело цикла.

| Выражение | Первая переменная | Вторая переменная |
| --- | --- | --- |
| [Массив][arrays], указатель на массив, [срез][slices] | Индекс элемента | Значение элемента |
| [Строка][strings] | Смещение в байтах | Кодовая точка типа `rune` |
| [Карта][maps] | Ключ | Значение по ключу |
| Канал | Принятое значение | — |
| Целое число `n` (Go 1.22+) | Число от `0` до `n-1` | — |
| Функция-итератор (Go 1.23+) | Первый аргумент `yield`, если он есть | Второй аргумент `yield`, если он есть |

С одной переменной цикл получает первое значение. Запись `for _, number := range numbers` пропускает
индекс и получает значение элемента. Чтобы изменить элемент массива или среза, запишите новое значение
по индексу.

Порядок обхода карты не определён. Канал перебирается до закрытия и чтения оставшихся значений.
Получение из `nil`-канала блокируется. Для `range n` при `n <= 0` итераций нет.

### Функции-итераторы

Начиная с Go 1.23, `range` может вызвать функцию-итератор, передав ей функцию `yield`.
Каждый вызов `yield` передаёт очередное значение телу цикла. Если тело выполняет `break`,
`yield` возвращает `false`, и итератор должен завершиться без новых вызовов `yield`.

```go
upToThree := func(yield func(int) bool) {
    for number := 1; number <= 3; number++ {
        if !yield(number) {
            return
        }
    }
}

for number := range upToThree {
    fmt.Println(number) // Сначала 1, затем 2 на отдельной строке.
    if number == 2 {
        break
    }
}
```

### Вычисление выражения `range`

Выражение справа от `range` обычно вычисляется один раз перед циклом.

При одной переменной итерации или без переменных выражение пропускается, если оно само или его `len` — константа.

### Перебор без итераций

Пустые массивы и строки, `nil`-срезы и `nil`-карты дают ноль итераций.

## Переменные итераций

Начиная с Go 1.22, переменная, объявленная через `:=` в заголовке цикла, создаётся заново на каждой итерации.
Запись через `=` присваивает значение уже объявленной переменной. Это видно, если сохранить функции,
которые обращаются к `i` после цикла.

```go
var separate, shared []func() int
for i := range 3 {
    separate = append(separate, func() int { return i })
}
var i int
for i = range 3 {
    shared = append(shared, func() int { return i })
}

fmt.Println(separate[0](), separate[1](), separate[2]()) // 0 1 2
fmt.Println(shared[0](), shared[1](), shared[2]())       // 2 2 2
```

Все функции читают `i` при вызове. У первого цикла каждая функция обращается к своей переменной,
а у второго все функции обращаются к одной переменной с последним записанным значением `2`.
Захват переменных подробно разобран в [уроке 014][closures].

В модуле версию языка для пакета обычно задаёт директива `go` в `go.mod`.
