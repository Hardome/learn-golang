# Урок 002. Переменные в Go

Ветка — `lesson-002-variables`. В файле [hello.go](hello.go) показано, как объявлять переменные с помощью `var` и `:=`.

| Запись | Что делает |
| --- | --- |
| `var name string` | Объявляет переменную с указанным типом и нулевым значением. Для `string` это `""`, для `int` — `0`, для `bool` — `false`. |
| `var name string = "Go"` | Объявляет переменную с указанным типом и начальным значением. |
| `var name = "Go"` | Объявляет переменную. Go выводит тип `string` из начального значения. |
| `name := "Go"` | Краткое объявление с выводом типа. Работает только внутри функций. |
| `name = "Golang"` | Присваивает новое значение уже объявленной переменной. |

Go чувствителен к регистру. В примере ниже `name` и `Name` — две разные переменные. После присваивания `name` содержит `"Язык Go"`, а `Name` содержит `"Golang"`.

```go
name := "Go"
Name := "Golang"
name = "Язык Go"
fmt.Println(name, Name)
```

Имя `Println` экспортируется из пакета `fmt`: оно начинается с заглавной буквы Unicode и объявлено на уровне пакета. Локальная переменная `Name` видна только в своей области видимости.

## Область видимости и пограничные случаи

- `var` работает на уровне пакета и внутри функций. Внутри блока имя локальной переменной становится видимым после объявления. `var value = value` во внутреннем блоке может взять начальное значение из внешней переменной с тем же именем.
- Краткое объявление `:=` требует хотя бы одного нового имени, отличного от `_`. Существующее имя из того же блока с тем же типом получает новое значение. Поэтому после `count := 1` запись `count, next := 2, 3` обновляет `count` и объявляет `next`. Одиночное `count := 2` в том же блоке не компилируется.
- Во вложенном блоке новое объявление может затенить внешнюю переменную. После окончания блока снова видно внешнее имя. При работе с `err` это важно: `:=` во вложенном блоке может создать отдельную переменную.
- Нулевое значение зависит от типа. Для указателей, срезов, карт, каналов, функций и интерфейсов это `nil`. Выражению `nil` нужен контекст типа: `var p *int = nil` допустимо, а `var p = nil` не компилируется. Используйте `_`, чтобы явно отбросить ненужное значение.

## Запуск

Запустите `go run hello.go`. Ожидаемый вывод:

```text
short short 2 short 3
Язык Go Golang
Внутренний count: 9
Внешний count и next: 2 3
```
