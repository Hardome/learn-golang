# Урок 004. Константы в Go

В [hello.go](hello.go) показано, как объявлять константы с помощью `const`. Их значения известны во время компиляции.
Константу объявляют сразу со значением. Попытка изменить это значение вызывает ошибку компиляции. Объявлять константы
можно как на уровне пакета, так и внутри функции.

## Объявление и тип

- `const appName string = "Go"` — Типизированную строковую константу.
- `const defaultRetries = 3` — Нетипизированную целочисленную константу.
- `const secondsPerHour = 60 * secondsPerMinute` — Константу, вычисленную из литерала и другой константы. При
  `secondsPerMinute = 60` получится `3600`.

Константы бывают логическими, строковыми и числовыми. При присваивании нетипизированной константы переменной Go
проверяет, помещается ли значение в тип переменной. Например, `3` подходит для `uint8` и `int64`, а `256` выходит за
пределы диапазона `uint8`.

```go
const defaultRetries = 3
var retries8 uint8 = defaultRetries
var retries64 int64 = defaultRetries
// const retries = retries8 // Ошибка компиляции: retries8 — переменная.
```

## Блок `const` и `iota`

В блоке `const (...)` первая строка объявления содержит выражение. Если ниже его опустить, Go повторит список выражений
и указанный тип из ближайшей предыдущей строки, где они были записаны. Поэтому `mediumLimit` получает `int(1)`, а
`maxLimit` — `int(3)`.

```go
const (
    smallLimit int = 1
    mediumLimit
    largeLimit int = 3
    maxLimit
)
```

`iota` — индекс объявления внутри блока `const`. Он начинается с `0` в каждом блоке и увеличивается на единицу для
каждого следующего объявления. Блок из программы повторяет выражение `1 << iota`. Оператор `<<` сдвигает единичный бит
влево, поэтому получаются значения `1`, `2` и `4`.

```go
const (
    readMask = 1 << iota // 1 << 0 = 1
    writeMask           // 1 << 1 = 2
    executeMask         // 1 << 2 = 4
)
```

## Константные выражения и пределы

- Нетипизированная константа получает тип по умолчанию, когда контекст не задаёт другой. Поэтому `value := 3` объявляет
  `int`, а `var value uint8 = 3` использует `uint8`. Присваивание `256` переменной `uint8` не компилируется.
- Числовые константы представляют точные значения произвольной точности в модели языка. Реализации могут ограничивать
  внутреннюю точность в пределах, указанных спецификацией. `1 << 100` допустимо вычислять как константу, а
  `var huge int64 = 1 << 100` не компилируется. Проверка зависит от типа, в который нужно поместить результат.
- `len("Go")` — константа. Для массива или указателя на массив `len` и `cap` тоже могут быть константами, когда операнд
  не содержит приёмов из канала или неконстантных вызовов функций. `nil` и составные литералы вроде `[2]int{1, 2}` сами
  по себе константами не являются.
- `iota` пересчитывается для каждой спецификации внутри `const`, а не для каждого имени. В строке `a, b = iota, iota`
  оба значения одинаковые. Объявление с `_` тоже занимает позицию. В отдельном `const` счёт начинается заново.

Выполните `go run hello.go` из каталога урока. Ожидаемый вывод также указан в комментариях рядом с вызовами печати.

```text
60 3600

После сдвига: 4

```
