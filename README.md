# Урок 012. Функции и их параметры в Go

Функция — именованный или анонимный блок кода, который можно вызвать. Функция может принимать входные данные и
возвращать один или несколько результатов вызывающему коду.

Параметры — имена и типы входных данных в объявлении функции. Аргументы — конкретные значения, которые передают
при вызове.

## Объявление функции

```go
func plus(a, b int) int {
    return a + b
}
```

- `func plus` начинает объявление функции с именем `plus`.
- `a, b int` объявляет два параметра типа `int`.
- Последний `int` задаёт тип результата.
- `return a + b` возвращает сумму.

Если функция ничего не возвращает, тип результата опускают, как в `func saySomething(message string)`.

## Вызов функции

В `plus(3, 4)` числа `3` и `4` — аргументы. Вызов возвращает `7`.

Результат одного вызова можно передать в другой. В `plus(plus(1, 2), 4)` внутренний вызов возвращает `3`, и внешний
вызов получает аргументы `3` и `4`.

## Типы функций

Тип функции `plus` — `func(int, int) int`.

Идентичность типов функций зависит от порядка и типов параметров и результатов. Имена параметров и результатов
служат для читаемости.

Вариативность тоже входит в тип функции. Типы `func(...int)` и `func([]int)` различаются.

Функцию можно сохранить в переменной. В `operation := plus` переменная получает функцию `plus`, а выражение
`operation(3, 4)` вызывает её.

Функцию можно передать как аргумент, если у параметра подходящий тип. `apply` принимает функцию `op` и вызывает её.

```go
func apply(a, b int, op func(int, int) int) int {
    return op(a, b)
}
```

В вызове `apply(3, 4, plus)` параметр `op` получает функцию `plus`.

Вызов функционального значения `nil` вызывает `panic`.

## Несколько результатов

Если результатов несколько, их типы перечисляют в скобках. У `swap` оба результата имеют тип `int`.

```go
func swap(a, b int) (int, int) {
    return b, a
}
```

Функция `swap` возвращает аргументы в обратном порядке. Вызов `left, right := swap(1, 2)` записывает `2` в `left`
и `1` в `right`.

## Именованные возвращаемые результаты

Результатам можно дать имена в объявлении функции. Эти имена доступны внутри функции как локальные переменные.

Именованные результаты получают нулевые значения своих типов. У `area` и `perimeter` начальное значение `0`.

```go
func rectangle(width, height int) (area, perimeter int) {
    area = width * height
    perimeter = 2 * (width + height)
    return
}
```

`return` без выражений возвращает текущие значения в порядке объявления результатов. В `rectangle` он равносилен
`return area, perimeter`.

Вызов `rectangle(3, 4)` возвращает площадь `12` и периметр `14`.

### Затенение результата

Если внутри вложенного блока объявить ещё одну переменную `area`, имя `area` в этом блоке будет относиться к ней.
Именованный результат при этом затенён, и компилятор вправе отклонить `return` без выражений в этом блоке.

Явный `return value` показывает, какое значение возвращается в этой ветке.

### Именованный результат и `defer`

`defer` откладывает вызов до выхода из функции. Отложенная функция может изменить именованный результат.

```go
func resultAfterDefer() (result int) {
    defer func() {
        result++
    }()
    return 10
}
```

В `resultAfterDefer` возврат происходит по шагам.

1. `return 10` записывает `10` в `result`.
2. Отложенное замыкание увеличивает `result` на единицу.
3. Вызывающий код получает итоговое значение `11`.

## Передача по значению

Go передаёт аргументы по значению. При вызове каждый параметр получает копию соответствующего аргумента.

```go
func addTwenty(x int) {
    x += 20
}
```

Если `a := 8`, вызов `addTwenty(a)` увеличивает локальный `x` до `28`. В `a` по-прежнему хранится `8`.

При передаче среза копируется значение среза. Элементы могут оставаться в общей памяти, поэтому изменение элемента
видно вызывающему коду.

При передаче указателя копируется указатель. Через копию функция обращается к исходному объекту.

## Переменное число аргументов

Параметр вида `numbers ...int` может стоять только последним.

Вариативный параметр принимает любое количество аргументов указанного типа, включая ноль.

Внутри функции `numbers` имеет тип `[]int`, поэтому его элементы можно перебрать через `range`.

```go
func sum(numbers ...int) int {
    total := 0
    for _, number := range numbers {
        total += number
    }
    return total
}
```

| Вызов | Результат |
| --- | --- |
| `sum(1, 2, 3)` | `6` |
| `sum()` | `0` |
| `sum(values...)` при `values := []int{4, 5}` | `9` |

### Отдельные аргументы

Отдельные аргументы для вариативного параметра собираются в новый срез.

При вызове `sum()` параметр `numbers` равен `nil`.

### Передача среза

Троеточие после `values` передаёт существующий срез без создания нового. Внутри `setFirst` срез `numbers` использует
тот же массив, что и `values`.

```go
func setFirst(replacement int, numbers ...int) {
    if len(numbers) > 0 {
        numbers[0] = replacement
    }
}
```

Если `values := []int{4, 5}`, после `setFirst(7, values...)` в первом элементе `values` хранится `7`.

Для одного вариативного параметра нельзя смешивать отдельные аргументы и срез с `...`.
