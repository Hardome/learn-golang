# Урок 010. Условные конструкции в Go

Условные конструкции выбирают блок кода по результату проверки. В [hello.go](hello.go) показаны `if`, `else if`, `else`
и две формы `switch`.

## `if`, `else if` и `else`

Go проверяет условия сверху вниз и выполняет первую подходящую ветку. Блок `else` выполняется, если все проверки дали
`false`. Ветки `else if` и `else` можно опустить.

При `a = 5`, `b = 6` и `c = 5` сравнения `a > b` и `a > c` дают `false`. Срабатывает `else`, из чего следует `a <= b` и
`a <= c`. Равенство `a` и `c` показывает, зачем здесь нужен знак `<=`.

Перед условием можно выполнить короткую инструкцию. В записи `if remainder := 17 % 3; remainder == 0 {` переменная
`remainder` доступна в условии и во всех ветках этой конструкции. В примере остаток равен `2`, поэтому ветка `else`
формирует строку `остаток 2`.

## `switch`

- `switch value` — Значение сравнивается с вариантами в `case`. Несколько вариантов можно перечислить через запятую,
  например `case 3, 4:`.
- `switch { ... }` — Каждый `case` задаёт логическое условие. Выполняется ветка с первым истинным условием.

Если совпадений нет, выполняется `default`, когда он указан. Обычно после выбранной ветки Go выходит из `switch`
автоматически.

Инструкция `fallthrough` в конце ветки сразу передаёт управление следующей ветке, пропуская её проверку. При `value = 5`
выполняются блоки `case 5` и `case 6`. При `value = 4` выполняется только общий блок для `3` и `4`. Значение `7`
попадает в `default`.

Во втором `switch` температура `18` не подходит под условия `temperature < 0` и `temperature >= 25`, поэтому выполняется
`default`.

## Область видимости и переключение по типу

- Короткая инструкция перед условием `if` выполняется перед проверкой. Объявленные в ней переменные видны в условии и во
  всех ветках этой конструкции. После закрывающей скобки всей конструкции область видимости заканчивается.
- У `switch` тоже может быть короткая инструкция. Например, `switch value := readValue(); value {` вычисляет значение
  один раз. `case` проверяются по порядку до первого совпадения, поэтому поздние выражения с побочными эффектами могут
  не выполниться. `default` можно разместить в любом месте.
- `fallthrough` допустим в конце ветки обычного `switch`, у которой есть следующая ветка. Он запускает тело следующей
  ветки сразу. В `switch` по типу `fallthrough` запрещён.
- `switch x := value.(type)` сопоставляет динамический тип интерфейса с вариантами. В ветке с одним конкретным типом
  переменная `x` имеет этот тип. В ветке с несколькими типами или в `default` она сохраняет исходный интерфейсный тип.
  `case nil` срабатывает для интерфейса без динамического типа.

## Запуск

Выполните `go run hello.go` из каталога урока. Ожидаемый вывод указан и в комментариях к вызовам печати.

```text
Сравнение: a <= b и a <= c
17 / 3: остаток 2
switch(4), case 3 или 4
switch(5), case 5
switch(5), case 6
switch(7), default
На улице: умеренно
Динамический тип: int 42
```
