# Урок 016. Указатели в Go

Указатель — это значение, которое хранит адрес переменной. Зная этот адрес, можно прочитать или изменить
значение переменной через указатель. Тип указателя зависит от того, на что он указывает. Например,
`*int` — указатель на переменную типа `int`, а `*float64` — на переменную типа `float64`.

Примеры можно запустить из [hello.go](hello.go) командой `go run hello.go`.

## Как объявить указатель и получить адрес

```go
var x int = 4
var p *int
p = &x

fmt.Printf("Адрес: %p\n", p) // например, Адрес: 0xc000010100
fmt.Println("Значение:", *p) // Значение: 4

*p = 25
fmt.Println(x) // 25
```

- `var p *int` объявляет переменную, в которой можно хранить указатель на `int`.
- `&x` берёт адрес `x`. У `x` тип `int`, поэтому у `&x` тип `*int` и его можно присвоить `p`.
- `*p` обозначает переменную по адресу из `p`. Эта операция называется **разыменованием**.
  Чтение `*p` даёт значение `x`, а присваивание `*p = 25` меняет саму `x`.

`fmt.Printf` с форматом `%p` печатает адрес в шестнадцатеричном виде с префиксом `0x`. Конкретный адрес
может отличаться при каждом запуске. Число 4 в примере — значение по адресу, напечатанное через `*p`.

При коротком объявлении компилятор выводит тип указателя сам.

```go
temperature := 2.3
reading := &temperature // тип *float64
fmt.Println(*reading)   // 2.3
```

## Пустой указатель

Если объявить `var p *int` без начального значения, `p` будет равен `nil`. Такой указатель никуда
не указывает. Разыменование `nil` вызывает панику, в том числе в выражении `&*p`. Если указатель может быть
пустым, проверь его перед разыменованием.

```go
var p *int
fmt.Println(p == nil) // true
// fmt.Println(*p)    // паника

if p != nil {
    fmt.Println(*p) // эта строка пропускается
}
```

Поле типа `*int` удобно, когда нужно различать отсутствие значения (`nil`) и явный ноль (указатель
на переменную со значением 0). Если положить `nil` типа `*int` в интерфейс `any`, интерфейс будет
содержать динамический тип `*int` и сам уже не будет равен `nil`.

## Функция new

Встроенная функция `new(T)` создаёт новую переменную с нулевым значением типа `T` и возвращает указатель
`*T`. У созданной переменной нет собственного имени в исходном коде. Читать и менять её можно через указатель.

```go
p := new(int)
fmt.Println(*p) // 0
*p = 8
fmt.Println(*p) // 8
```

Например, `new([]int)` возвращает указатель на нулевой срез, а `make([]int, 2)` создаёт срез с двумя элементами
и возвращает сам срез. Начиная с Go 1.26, `new(42)` также допустимо и возвращает `*int` на новую переменную
со значением 42.

## Указатель на указатель

Переменная-указатель сама имеет адрес. Если `p` имеет тип `*int`, то `&p` имеет тип `**int`, то есть
«указатель на `*int`».

```go
number := 9
p := &number
pp := &p

fmt.Println(pp == &p, *pp == p, **pp) // true true 9

other := 20
*pp = &other
fmt.Println(*p, number) // 20 9
```

`pp` хранит адрес переменной `p`. Одно разыменование, `*pp`, даёт саму переменную `p`, которая хранит адрес
`number`. Второе разыменование, `**pp`, даёт значение `number`, пока `p` на неё указывает.
Присваивание `*pp = &other` меняет адрес, который хранится в `p`.

## Массив указателей

Тип `[4]*int` — массив из четырёх указателей на `int`. Если объявить `var pointers [4]*int`, все элементы
будут равны `nil`. Адреса можно присвоить по индексам или перечислить в литерале массива.

```go
first, second, fourth := 1, 2, 4
pointers := [4]*int{&first, &second, nil, &fourth}
fmt.Println(pointers[2] == nil) // true

for _, p := range pointers {
    if p != nil {
        fmt.Println(*p) // 1, 2, 4 на отдельных строках
    }
}
```

`[4]*int` хранит четыре указателя. Тип `*[4]int` означает один указатель на весь массив из четырёх чисел.

## Копирование и сравнение указателей

Присваивание копирует указатель. Обе копии содержат один адрес, поэтому изменение через одну видно через другую.

```go
score := 10
pointer := &score
alias := pointer
*alias = 15
fmt.Println(score, *pointer, pointer == alias) // 15 15 true
```

Два указателя одного типа равны, если указывают на одну переменную или оба равны `nil`. Указатели на разные
переменные нулевого размера, например `struct{}`, могут быть равны. Для обычных указателей доступны
`==` и `!=`. Арифметика вроде `pointer + 1` не поддерживается. Число типа `uintptr` имеет целочисленную
семантику и само по себе не удерживает объект от сборки мусора.

## Указатель как параметр

Go передаёт аргументы по значению. Параметр типа `*int` получает копию адреса, поэтому через него можно изменить
переменную вызывающего кода. Присваивание самому параметру меняет только локальную копию указателя.

```go
func increment(target *int) {
    *target = *target + 1
}

func redirect(target, replacement *int) *int {
    target = replacement
    return target
}
```

```go
score, backup := 10, 99
pointer := &score
increment(pointer)
fmt.Println(score) // 11

redirect(pointer, &backup)
fmt.Println(*pointer) // 11
pointer = redirect(pointer, &backup)
fmt.Println(*pointer) // 99
```

Если функция должна заменить сам указатель вызывающего кода, обычно проще вернуть новый указатель.
Чтобы функция могла присвоить адрес самой переменной-указателю, передай ей адрес этой переменной с типом `**T`.

Для небольших значений удобно принимать значение и возвращать результат. Указатель полезен для изменения
существующего объекта, представления отсутствия значения или уменьшения стоимости копирования больших структур.
При совместном использовании изменяемого объекта из нескольких горутин нужен согласованный доступ к нему.

## У каких выражений можно взять адрес

Можно взять адрес переменной, адресуемого поля структуры, элемента адресуемого массива или элемента среза.
Литерал составного типа — отдельное исключение. Например, `&Point{X: 3}` создаёт новую переменную сразу.

```go
type Point struct{ X int }

point := &Point{X: 3}
point.X = 4 // то же, что (*point).X = 4
fmt.Println(point.X) // 4

numbers := []int{1, 2}
element := &numbers[0]
*element = 7
fmt.Println(numbers) // [7 2]
```

У константы, строкового элемента, результата вызова функции и элемента карты адрес взять нельзя. Например,
`&42`, `&len(numbers)` и `&scores["go"]` не компилируются. Чтобы хранить указатели в карте, можно объявить
`map[string]*int` и явно положить туда адрес переменной.

В `for _, value := range numbers` выражение `&value` даёт адрес переменной цикла, в которую скопировали элемент.
Для указателя на сам элемент используй `&numbers[index]`. Если `append` выделит новый базовый массив,
старый указатель останется привязан к элементу прежнего массива.

## Время жизни

Можно вернуть адрес локальной переменной. Она остаётся доступной, пока её можно достичь через указатель.

```go
func newScore(initial int) *int {
    score := initial
    return &score
}
```

Выбор стека или кучи делает компилятор, в том числе с помощью анализа убегания. Само использование `&` или `new`
не гарантирует размещение в куче. Диагностику текущего компилятора можно посмотреть командой
`go build -gcflags=-m hello.go`.
