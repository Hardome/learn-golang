# Урок 022. Пакеты и их импорт

Пакет объединяет код, который решает одну задачу. Например, пакет `fmt` умеет выводить текст, а пакет `math`
содержит математические функции. Чтобы воспользоваться готовой функцией, подключите её пакет через `import`.

Примеры для практики собраны в [hello.go](hello.go). Запустить их можно командой `go run hello.go`.

## С чего начинается программа

Каждый Go-файл начинается со строки `package`. Она говорит, к какому пакету относится файл. Перед ней могут
стоять комментарии. Если мы пишем программу, которую нужно запустить, используем `package main`.
После подготовки пакетов Go вызовет функцию `main`. У неё нет параметров и возвращаемых значений.

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет, Go!") // Привет, Go!
}
```

Здесь `import "fmt"` подключает пакет из стандартной библиотеки. В записи `fmt.Println` слева от точки стоит
имя пакета, справа — имя функции. Другие программы могут импортировать обычные пакеты. Пакет `main` служит
точкой входа в программу, и команда `go` запрещает его импортировать. Когда функция `main` заканчивает работу,
завершается вся программа.

## Как подключить несколько пакетов

Можно написать отдельное объявление для каждого пакета.

```go
import "fmt"
import "math"
```

Когда импортов несколько, их обычно записывают одной группой.

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    fmt.Println(math.Pow(2, 3)) // 8, то есть 2 в третьей степени.
}
```

### Что писать в кавычках и перед точкой

В кавычках указывают **путь импорта**. По нему Go находит нужный пакет. Перед точкой по умолчанию пишут имя
из строки `package` этого пакета. Чаще всего это последняя часть пути. Например, пакет `"encoding/base64"`
называется `base64`. Есть исключения. Пакет `"math/rand/v2"`, появившийся в Go 1.22, называется `rand`.

```go
// В файле импортированы "encoding/base64" и "fmt".
encoded := base64.StdEncoding.EncodeToString([]byte("Go"))
fmt.Println(encoded) // R28=
```

Из другого пакета доступны **экспортируемые** имена. У них первая буква заглавная. Например, в `net/url` можно
создать значение типа `url.URL`, заполнить поле `Host` и вызвать метод `String`.

```go
// В файле импортированы "fmt" и "net/url".
address := url.URL{Host: "example.org"}
fmt.Println(address.String()) // //example.org
```

Правило заглавной буквы относится к именам уровня пакета, полям и методам. Локальная переменная видна только
в своём блоке, даже если назвать её с заглавной буквы.

### Что делать, если имена пакетов совпали

У пакетов `"html/template"` и `"text/template"` одно имя — `template`. Чтобы использовать оба в одном файле,
одному можно дать новое имя. Его пишут перед путём.

```go
package main

import (
    "fmt"
    "html/template"
    texttemplate "text/template"
)

func main() {
    fmt.Println(template.New("page").Name())     // page
    fmt.Println(texttemplate.New("note").Name()) // note
}
```

Это имя действует только в текущем файле. Внутри функции его можно случайно затенить локальной переменной.
Например, после `fmt := "отчёт"` в том же блоке `fmt.Println` вызовет ошибку, потому что `fmt` теперь строка.

### Импорт с точкой (dot import)

Если перед путём поставить точку, экспортируемые имена уровня пакета можно писать без имени пакета.

```go
package main

import (
    . "fmt"
    . "math"
)

func main() {
    Println(Pow(2, 3)) // 8, Println пришла из fmt, а Pow из math.
}
```

С обычным импортом по `math.Pow` сразу видно, откуда взялась функция. Импорт с точкой скрывает эту подсказку.
Если два пакета добавят в файл одно и то же имя, программа не соберётся. Например, оба пакета `template`
из предыдущего примера объявляют функцию `New`.

### Зачем нужен импорт с подчёркиванием

Если подключить пакет и ни разу к нему не обратиться в этом файле, Go сообщит об ошибке. Когда пакет больше
не нужен, импорт можно удалить.

Иногда пакет нужен ради действия, которое он выполняет при запуске программы. Для этого перед путём пишут `_`.

```go
import (
    "image"
    _ "image/gif" // Подключаем поддержку GIF для пакета image.
)
```

Например, при запуске `image/gif` регистрирует декодер GIF. После этого `image.DecodeConfig` может распознать
GIF и прочитать его размеры. Обращаться к функциям через имя `gif` с таким импортом нельзя. Рабочий пример
в [hello.go](hello.go) выводит `1 1 gif` для картинки размером в один пиксель. Если убрать строку
`_ "image/gif"`, пример получит ошибку `image.ErrFormat`.

## Где Go ищет пакеты

Пакеты стандартной библиотеки поставляются вместе с Go. Например, исходники `net/http` лежат в каталоге
`src/net/http` внутри дерева Go. Его расположение показывает команда `go env GOROOT`.

Для своего пакета в модульном проекте путь обычно складывается из пути модуля и имени подкаталога. Например,
если путь модуля — `example.org/app`, а пакет лежит в папке `greeting`, его подключают так.

```go
import "example.org/app/greeting"
```

Запись `import "./greeting"` в модульном режиме не работает. Команда `go run .` при этом допустима.
Точка в команде означает «собери пакет из текущего каталога».

Если пакет поставляется в стороннем модуле, Go определяет, какая версия модуля нужна проекту. Скачанные модули
хранятся в кеше. Его путь показывает `go env GOMODCACHE`. При сборке в режиме `-mod=vendor` Go берёт исходники
зависимостей из папки `vendor`. Как настраивать модули, скачивать зависимости и заполнять `vendor`, разберём
в следующих уроках.

## Как собрать пакет из нескольких файлов

Положим в один каталог два файла с объявлением `package main`. В файле `hello.go` опишем функцию.

```go
package main

import "fmt"

func sayHello() {
    fmt.Println("Привет, Go!") // Привет, Go!
}
```

В файле `main.go` вызовем её.

```go
package main

func main() {
    sayHello() // Привет, Go! Функция объявлена в соседнем файле этого пакета.
}
```

Функция `sayHello` доступна в обоих файлах, хотя её имя начинается со строчной буквы. Имя `fmt` видно только
в `hello.go`. Если понадобится вызвать `fmt.Println` в `main.go`, туда тоже нужно добавить `import "fmt"`.

```text
go run main.go hello.go
go build -o app.exe main.go hello.go
```

Первая команда выведет `Привет, Go!`. Вторая создаст `app.exe`. На Linux и macOS имя можно задать как `-o app`.
Если передать только `main.go`, Go не увидит `sayHello` и выдаст ошибку `undefined: sayHello`.

В каталоге пакета внутри модуля обычно запускают `go run .` или `go build .`. Тогда Go сам выбирает нужные
файлы. Например, при сборке для Windows он учтёт файл с суффиксом `_windows.go`. При явном перечислении
файлов Go берёт именно указанные файлы, даже если у них есть ограничения сборки. Файлы `*_test.go` предназначены
для `go test`. В них можно объявить отдельный пакет, например `greeting_test`, чтобы проверять только открытый
интерфейс пакета `greeting`.

## Что могут спросить на собеседовании

### Можно ли замкнуть цепочку импортов

Если пакет `a` импортирует `b`, а `b` импортирует `a`, Go выдаст ошибку `import cycle not allowed`. То же правило
работает для цепочки любой длины, в том числе для импортов с `_`. Один из способов разорвать цикл — вынести
общую часть в третий пакет, который импортируют и `a`, и `b`.

Импорт также не передаётся по цепочке. Если `a` импортирует `b`, а `b` использует `fmt`, пакет `a` всё равно
должен сам импортировать `fmt` в каждом файле, где вызывает его функции.

### Когда выполняется `init`

Go подготавливает каждый пакет один раз за запуск, даже если его импортируют из нескольких мест. Сначала
готовятся пакеты, которые он импортирует. В самом пакете Go сначала задаёт значения переменных уровня пакета,
затем вызывает функции `init`. Только после подготовки всех пакетов запускается `main`.

```go
package main

import "fmt"

var message = "Привет"

func init() {
    message += ", Go!" // Переменная уже получила начальное значение.
}

func main() {
    fmt.Println(message) // Привет, Go!
}
```

Функций `init` может быть несколько. Go вызывает их по очереди в том порядке, в каком они идут в исходниках,
переданных компилятору. Вызвать `init` напрямую нельзя. Если `init` запускает горутину, Go не ждёт её завершения,
поэтому для ожидания понадобится явная синхронизация.

При инициализации переменных зависимость важнее порядка строк. Например, если `var total = price * 2` записано
выше `var price = 21`, Go всё равно сначала задаст `price`, поэтому `total` получит значение `42`. Go находит
такие зависимости и в телах функций. Скрытую зависимость, например через вызов метода интерфейса, он может
не учесть. Цикл между переменными, который Go обнаружит, приведёт к ошибке компиляции.

С Go 1.21 спецификация прямо задаёт порядок между пакетами, которые уже можно подготовить. Из них Go берёт
первый при сортировке по пути импорта. Перестановка строк в `import (...)` этот порядок не меняет.

### Что означает папка `internal`

Если пакет лежит в `example.org/app/web/internal/session`, его может подключить `example.org/app/web/handler`.
У обоих путей общая часть до `internal` — `example.org/app/web`. Пакет `example.org/app/cli` подключить
`session` не сможет, даже если все нужные функции в нём экспортированы.
