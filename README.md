# Урок 002. Переменные в Go

Переменная хранит значение определённого типа. Объявление вводит имя переменной и задаёт её тип.
Присваивание через `=` записывает новое значение в уже объявленную переменную.

## Объявление и присваивание

```go
var count int
fmt.Println(count) // 0

count = 1
fmt.Println(count) // 1
```

В объявлении `var count int` тип задан явно. Начального значения справа нет, поэтому `count` получает
**нулевое значение** типа `int`. Присваивание `count = 1` сохраняет число в той же переменной.

Нулевое значение зависит от типа. У `string` это `""`, у `bool` это `false`, а у указателей, срезов, карт,
каналов, функций и интерфейсов это `nil`. Выражению `nil` нужен контекст типа. Запись `var p *int = nil`
задаёт тип указателя, а `var p = nil` вызывает ошибку компиляции.

## Краткое объявление

Продолжим пример в том же блоке.

```go
count, next := 2, 3
fmt.Println(count, next) // 2 3
// count, _ := 4, 5      // Ошибка компиляции. В этом блоке нет нового имени.
```

`:=` объявляет `next`. Тип выводится из литерала `3`, поэтому `next` получает тип `int`.
Имя `count` уже объявлено в этом блоке и сохраняет свой тип. Оно получает новое значение `2`.
Для краткого объявления нужно хотя бы одно новое имя, отличное от `_`. Пустой идентификатор `_`
отбрасывает значение.

| Возможность | `var` | `:=` |
| --- | --- | --- |
| Объявить переменную | В пакете и внутри функций | Внутри функций |
| Задать тип `int64` | `var limit int64 = 5` | `limit := int64(5)` |
| Вывести тип из значения | `var limit = 5` | `limit := 5` |
| Получить нулевое значение без инициализатора | `var limit int64` | Справа требуется выражение |
| Повторить имя в том же блоке | Ошибка компиляции | Допустимо вместе с новым именем |

Внутри функции для объявления с начальным значением обычно используют `:=`. Для обновления одного
существующего значения достаточно `=`. Имена чувствительны к регистру, поэтому `name` и `Name` обозначают
разные переменные.

## Область видимости и затенение

У локальной переменной область видимости начинается в конце объявления и продолжается до конца блока.
Во вложенном блоке можно объявить переменную с тем же именем, что и у внешней.
Такое имя **затеняет** внешнее на время действия внутренней области видимости.

```go
// Внешние count и next уже равны 2 и 3.
{
    count := 9
    fmt.Println(count) // 9
}
fmt.Println(count, next) // 2 3
```

Внутренний `count` хранит собственное значение. Когда блок завершается, `count` снова обозначает внешнюю
переменную со значением `2`. По этой причине `err := ...` во вложенном блоке может создать свою переменную.
Для обновления внешней переменной используют `err = ...`.

Запустите полную последовательность из [hello.go](hello.go) командой `go run hello.go`.
