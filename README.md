# Урок 007. Поразрядные операции в Go

В [hello.go](hello.go) операции выполняются над отдельными битами целых чисел. Для примеров выбран `uint8`, чтобы в каждом значении было восемь битов. Формат `%08b` в `fmt.Printf` выводит двоичную запись и дополняет её ведущими нулями до восьми символов.

## Операторы

Пусть `a = 0b00001100` (12), а `b = 0b00001010` (10). Префикс `0b` обозначает двоичный литерал.

| Выражение | Как определяется результат | Двоичный результат |
| --- | --- | --- |
| `a & b` | Бит равен 1, если он равен 1 у обоих операндов. | `00001000` |
| `a \| b` | Бит равен 1, если он равен 1 хотя бы у одного операнда. | `00001110` |
| `a ^ b` | Бит равен 1, если биты операндов различаются. | `00000110` |
| `a &^ b` | Каждый установленный бит в `b` сбрасывает соответствующий бит в `a`. | `00000100` |
| `^a` | Каждый 0 меняется на 1, каждый 1 — на 0. | `11110011` |
| `a << 1` | Биты сдвигаются на одну позицию влево. | `00011000` |
| `a >> 1` | Биты сдвигаются на одну позицию вправо. | `00000110` |

У беззнаковых чисел освободившиеся при сдвиге позиции заполняются нулями. У знаковых чисел сдвиг вправо заполняет старшие позиции знаковым битом. Количество позиций сдвига должно быть целым и неотрицательным.

## Маска флагов

В программе чтение, запись и выполнение занимают по одному биту. Чтобы проверить флаг, используйте `flags&write != 0`. Оператор `|` устанавливает выбранные биты, а `&^` сбрасывает их.

```go
flags := read | execute
flags = flags | write
flags = flags &^ execute
```

## Запуск

Выполните `go run hello.go` из каталога урока.

```text
a = 00001100, b = 00001010
a & b  = 00001000
a | b  = 00001110
a ^ b  = 00000110
a &^ b = 00000100
^a     = 11110011
a << 1 = 00011000
a >> 1 = 00000110
Исходные флаги: 00000101
Запись разрешена: false
Разрешили запись: 00000111
Запретили выполнение: 00000011
```
