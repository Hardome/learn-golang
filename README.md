# Изучаем Go

Учебный проект по Go. Каждый урок находится в отдельной ветке. Имена веток имеют формат `lesson-NNN-topic`, где `NNN` — трёхзначный номер урока, а `topic` — короткое название темы на английском через дефисы. Благодаря ведущим нулям ветки идут по порядку при сортировке по имени.

## Урок 001. Hello, world!

Ветка — `lesson-001-hello-world`. Программа в файле [hello.go](hello.go) выводит `Hello, world!`. Пакет `main` обозначает исполняемую программу, функция `main` служит точкой входа, а `fmt.Println` печатает строку и переводит курсор на новую строку.

### Команды

Установите Go и выполняйте команды из каталога с файлом `hello.go`.

| Команда | Что делает |
| --- | --- |
| `go version` | Показывает установленную версию Go, операционную систему и архитектуру. |
| `go run hello.go` | Компилирует и сразу запускает программу. В каталоге проекта исполняемый файл не появляется. |
| `go build hello.go` | Собирает исполняемый файл в текущем каталоге. На Windows это `hello.exe`, на Linux и macOS — `hello`. |

После сборки запустите файл командой `./hello` на Linux или macOS либо `.\hello.exe` в PowerShell. Ожидаемый вывод — `Hello, world!`.
