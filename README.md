# Урок 012. Функции и их параметры в Go

В [hello.go](hello.go) показано, как объявлять и вызывать функции, передавать аргументы и получать результаты.

## Объявление и вызов

```go
func plus(a, b int) int {
    return a + b
}
```

- `func` начинает объявление функции, а `plus` — её имя.
- `a` и `b` — параметры. Запись `a, b int` задаёт тип `int` обоим параметрам.
- Последний `int` задаёт тип результата, а `return` возвращает значение.
- В вызове `plus(3, 4)` числа `3` и `4` — аргументы. Вызов возвращает `7`.

Сигнатуру задают типы параметров и результатов. Например, у `plus` тип функции `func(int, int) int`. Если функция ничего не возвращает, тип результата опускают, как в `func saySomething(message string)`. Результат одного вызова можно передать в другой. Так работает `saySomething(greeting("Анна"))`.

Если результатов несколько, их типы перечисляют в скобках. Функция `swap(a, b int) (int, int)` возвращает аргументы в обратном порядке. Вызов `left, right := swap(1, 2)` записывает `2` в `left` и `1` в `right`.

## Передача по значению

Go передаёт аргументы по значению. Когда вызывается `addTwenty(a)`, параметр `x` получает копию числа `8`. После `x += 20` внутри функции `x` равен `28`, а в переменной `a` у вызывающего кода по-прежнему хранится `8`.

## Переменное число аргументов

Параметр вида `numbers ...int` может стоять только последним. Он принимает любое количество аргументов типа `int`, включая ноль. Внутри функции `numbers` имеет тип `[]int`, поэтому его элементы можно перебрать через `range`.

| Вызов | Результат |
| --- | --- |
| `sum(1, 2, 3)` | `6` |
| `sum()` | `0` |
| `sum(values...)` при `values := []int{4, 5}` | `9` |

Троеточие после `values` передаёт элементы среза в вариативный параметр.
