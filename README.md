# Урок 028. Строки и руны

Строка (`string`) в Go хранит последовательность байтов. **Байты уже созданной строки неизменяемы**.
Строка может содержать как текст в UTF-8, так и произвольные байты.

- `byte` — псевдоним `uint8`, тип одного байта строки.
- `rune` — псевдоним `int32`, которым в Go обозначают числовое значение кодовой точки Unicode.

Unicode задаёт кодовые точки, например `U+041F` для `П`. UTF-8 определяет, как записать эту точку байтами.
В строке `"Привет"` шесть кодовых точек и двенадцать байтов, потому что каждая буква занимает по два байта.

Фрагменты используют `fmt` и `unicode/utf8`. Команда `go run hello.go` запускает все рабочие примеры.
[Код примеров в hello.go](hello.go)

## Строка

### Строковые литералы

Двойные и обратные кавычки задают литералы `string`. Они по-разному обрабатывают обратную косую черту.

- В двойных кавычках `\n` записывает один байт перевода строки, а `\xNN` — байт с шестнадцатеричным значением `NN`.
- В обратных кавычках `\n` сохраняется как два байта, `\` и `n`. Перевод строки можно ввести прямо в исходнике.

Формат `%q` показывает строку в кавычках и делает управляющие символы видимыми.

```go
fmt.Printf("%q\n", "Go\n") // "Go\n"
fmt.Printf("%q\n", `Go\n`) // "Go\\n"
```

Буквы, написанные в исходнике напрямую, попадают в строку в UTF-8. Запись `"\xff"` вставляет байт `FF`.
Такой байт разрешён внутри `string`, хотя сам по себе он не образует корректный UTF-8.

### Чтение байта по индексу

**Индекс строки задаётся в байтах.** В `"Hello"` значение первого байта совпадает с номером кодовой точки `H`.
В UTF-8 коды ASCII занимают по одному байту. В `"Привет"` индекс `0` возвращает только первый байт буквы `П`.

```go
ascii := "Hello"
fmt.Println(len(ascii), ascii[0]) // 5 72

text := "Привет"
fmt.Println(len(text), text[0]) // 12 208
```

## Руна

Одинарные кавычки задают **литерал руны**. У `'П'` и `'\u041F'` одно числовое значение — `1055`. Чтобы
вывести сам знак, используйте `%c`. Если нужен результат типа `string`, `string(letter)` кодирует руну в UTF-8.

```go
var letter rune = 'П' // Можно также записать '\u041F' или 0x041F.
fmt.Println(letter)         // 1055
fmt.Printf("%c\n", letter)  // П
fmt.Println(string(letter)) // П
```

Размер значения `rune` в Go всегда **4 байта**, как у `int32`. В UTF-8 число байтов зависит от кодовой точки.

| Знак | Значение руны | Байтов в UTF-8 |
| --- | ---: | ---: |
| A | 65 | 1 |
| П | 1055 | 2 |
| € | 8364 | 3 |
| 😀 | 128512 | 4 |

Байты `D0 9F` нужно декодировать вместе по правилам UTF-8, чтобы получить `П`. Запись `0xD09F` сразу задаёт
число, которому в Unicode соответствует `킟`.

```go
var bytePairAsRune rune = 0xD09F
fmt.Printf("%c %U\n", bytePairAsRune, bytePairAsRune) // 킟 U+D09F
```

## Преобразования между строками и срезами

### Из строки в срез байтов

`[]byte(text)` даёт **один элемент на байт**. Срез можно передать в API для бинарных данных или изменить.
Запись в этот срез сохраняет исходное значение строки.

```go
text := "Привет"
bytes := []byte(text)
fmt.Println(bytes)      // [208 159 209 128 208 184 208 178 208 181 209 130]
fmt.Println(len(bytes)) // 12
```

### Из строки в срез рун

`[]rune(text)` декодирует UTF-8. Для корректного текста получается **один элемент на кодовую точку**.
Индекс `1` теперь относится ко второй руне `р`, которая в исходной строке начинается с байта `2`.

```go
text := "Привет"
letters := []rune(text)
fmt.Println(letters)          // [1055 1088 1080 1074 1077 1090]
fmt.Println(len(letters))    // 6
fmt.Printf("%c\n", letters[1]) // р
```

### Из среза байтов в строку

`string(bytes)` сохраняет порядок и значения байтов. Например, полученные из файла или из сети
байты UTF-8 станут строкой с тем же текстом. Преобразование выполняется и для некорректного UTF-8.

```go
bytes := []byte{208, 159, 209, 128, 208, 184, 208, 178, 208, 181, 209, 130}
fmt.Println(string(bytes)) // Привет
```

### Из среза рун в строку

`string(letters)` кодирует каждую руну в UTF-8 и собирает полученные байты. Для корректного UTF-8
цепочка `string([]rune(text))` возвращает строку с исходными байтами.

```go
letters := []rune{'П', 'р', 'и', 'в', 'е', 'т'}
fmt.Println(string(letters)) // Привет
```

## Перебор строки

В строке `"AБВ"` руны начинаются по байтовым смещениям `0`, `1` и `3`.

```text
Байтовый индекс    0 |  1   2 |  3   4
Байт (HEX)        41 | D0  91 | D0  92
Руна               A |    Б   |    В
```

### По байтам

Чтобы увидеть байты, пройдём по индексам от `0` до `len(text)-1`. В `"AБВ"` пять байтов, поэтому
обычный цикл с индексом сделает пять шагов.

```go
text := "AБВ"
for i := 0; i < len(text); i++ {
	fmt.Println(i, text[i]) // По строкам: 0 65, 1 208, 2 145, 3 208, 4 146
}
fmt.Printf("%c\n", text[1]) // Ð — число 208 трактуется как кодовая точка U+00D0.
```

При печати одного байта через `%c` его числовое значение становится кодовой точкой. Поэтому из байта `D0`
получается `Ð`. Для `Б` нужно декодировать пару `D0 91` целиком.

### По рунам через range

`for range` по строке на каждом шаге декодирует следующую руну и возвращает два значения.

- `offset` — **байтовое смещение начала руны**. После `A` оно увеличивается на один, после `Б` — на два.
- `letter` — значение руны, полученное из всей последовательности UTF-8.

```go
text := "AБВ"
for offset, letter := range text {
	fmt.Printf("%d: %c\n", offset, letter) // По строкам: 0: A, 1: Б, 3: В
}
```

### По индексам среза рун

У `В` в `[]rune` индекс `2`. В строке она начиналась с байта `3`. Если нужно прочитать руны по порядку,
достаточно `for range` по строке. Преобразование в срез удобно для доступа по номеру или замены руны.

```go
letters := []rune("AБВ")
for i := 0; i < len(letters); i++ {
	fmt.Printf("%d: %c\n", i, letters[i]) // По строкам: 0: A, 1: Б, 2: В
}
```

### Некорректный UTF-8

На некорректном UTF-8 `range` выдаёт руну замены `U+FFFD` и продвигается на один байт. Поэтому `!`
в примере остаётся по смещению `1`. Преобразование в `[]rune` тоже подставляет руну замены.

**Преобразование через `[]rune` теряет исходные некорректные байты.** Для их сохранения используйте `[]byte`.

```go
text := "\xff!"
fmt.Println(utf8.ValidString(text)) // false
for offset, letter := range text {
	fmt.Printf("%d: %U\n", offset, letter) // По строкам: 0: U+FFFD, 1: U+0021
}
fmt.Printf("% X\n", string([]rune(text))) // EF BF BD 21 — теперь записана руна замены.
```

## Получение длины строки

Для длины в байтах достаточно `len(text)`. Если нужен подсчёт рун, `utf8.RuneCountInString(text)`
проходит по строке один раз и возвращает счётчик. В текущей реализации это `O(n)` по числу байтов
и `O(1)` дополнительной памяти. Преобразование в `[]rune` даёт срез из `k` элементов, где `k` — число рун.
Такой срез полезен, если результат декодирования будет использован дальше. Спецификация определяет содержимое
среза, а фактические выделения памяти зависят от компилятора.

```go
text := "Привет"
fmt.Println(len(text))                    // 12 — байты.
fmt.Println(len([]rune(text)))            // 6 — руны.
fmt.Println(utf8.RuneCountInString(text)) // 6
```

В слове `"Привет"` все руны занимают по два байта, поэтому их начальные смещения идут с шагом два.

| Руна | Значение руны | Байты UTF-8 (HEX) | Байтовое смещение |
| --- | ---: | --- | ---: |
| П | 1055 | `D0 9F` | 0 |
| р | 1088 | `D1 80` | 2 |
| и | 1080 | `D0 B8` | 4 |
| в | 1074 | `D0 B2` | 6 |
| е | 1077 | `D0 B5` | 8 |
| т | 1090 | `D1 82` | 10 |

## Неизменяемость строк

Выражение `text[i]` даёт значение байта. **Байт строки не адресуем**, поэтому `text[i]` нельзя поставить
слева от `=` и нельзя получить его адрес через `&text[i]`. Правило действует для любой строки, включая
значение в обычной переменной.

```go
text := "Привет"
text[0] = 'A' // Ошибка компиляции: cannot assign to text[0].
```

### Замена руны

Чтобы заменить `П` на `О`, изменяем руну в срезе. Последующее присваивание меняет **значение переменной**
`text`. Переменная `original` по-прежнему содержит прежнюю строку.

```go
text := "Привет"
original := text

letters := []rune(text)
letters[0] = 'О'
text = string(letters)

fmt.Println(text, original) // Оривет Привет
```

## Получение подстроки

### Границы в байтах

В `text[:n]` граница `n` измеряется в байтах. `text[:2]` содержит всю букву `П`. **Граница может попасть внутрь
руны.** Например, `text[:3]` захватывает только первый байт буквы `р`. `% X` показывает эти байты,
а `utf8.ValidString` проверяет, образуют ли они корректный UTF-8.

```go
text := "Привет"
fmt.Println(text[:2]) // П
prefix := text[:3]
fmt.Printf("% X %t\n", prefix, utf8.ValidString(prefix)) // D0 9F D1 false
```

### Границы в рунах

У `[]rune` границы измеряются в элементах среза. Чтобы получить первые три кодовые точки, берём три руны
и кодируем их обратно. Для произвольного ввода сначала проверьте `len(letters) >= 3`.

```go
letters := []rune("Привет")
fmt.Println(string(letters[:3])) // При
```

## Отличие от JavaScript

JavaScript `.length` считает **16-битные кодовые единицы UTF-16**, Go `len` — **байты**. Для `😀`
в UTF-16 нужна пара единиц, а в UTF-8 — четыре байта.

| Строка | JavaScript `.length` | Go `len` |
| --- | ---: | ---: |
| `"Hello"` | 5 | 5 |
| `"Привет"` | 6 | 12 |
| `"😀"` | 2 | 4 |

Для корректного Unicode `Array.from(text)` в JavaScript и `[]rune(text)` в Go дают по одному элементу
на кодовую точку. В JavaScript элемент будет строкой, а в Go — числом типа `rune`.

## Руны и видимые символы

То, что читатель воспринимает как один знак, может состоять из нескольких кодовых точек. Например,
`e` и следующий за ней знак ударения образуют одну букву. Unicode описывает такие группы через
**графемные кластеры**. Для ограничения длины поля по видимым знакам нужен подсчёт кластеров.

| Текст | Байтов UTF-8 | Рун | Графемных кластеров |
| --- | ---: | ---: | ---: |
| `"А"` (кириллическая) | 2 | 1 | 1 |
| `"e\u0301"` | 3 | 2 | 1 |
| `"😀"` | 4 | 1 | 1 |
| `"👍🏽"` | 8 | 2 | 1 |
| `"🇷🇺"` | 8 | 2 | 1 |
| `"👨‍👩‍👧‍👦"` | 25 | 7 | 1 |

## Шпаргалка

| Задача | Операция |
| --- | --- |
| Узнать число байтов | `len(text)` |
| Узнать число рун | `utf8.RuneCountInString(text)` |
| Прочитать байт по индексу | `text[i]` |
| Прочитать руну по порядковому номеру | `letters[i]` после `letters := []rune(text)` |
| Перебрать руны с байтовыми смещениями | `for offset, r := range text` |
| Заменить руну | Изменить элемент `[]rune` и собрать строку через `string(letters)` |
| Собрать строку из одной руны | `string(r)` |
| Получить байты строки | `[]byte(text)` |
