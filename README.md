# Урок 005. Арифметические операции в Go

Арифметические операторы применяют операции к числам. Типы операндов влияют на результат: два целых операнда делятся
с отбрасыванием дробной части.

| Оператор | Операция | Пример | Результат |
| --- | --- | --- | --- |
| `+` | Сложение | `7 + 2` | `9` |
| `-` | Вычитание | `7 - 2` | `5` |
| `*` | Умножение | `7 * 2` | `14` |
| `/` | Деление | `7 / 2` | `3` |
| `%` | Остаток от деления целых чисел | `7 % 2` | `1` |

## Деление и остаток

При делении целых чисел дробная часть отбрасывается в сторону нуля. Поэтому `7 / 2` даёт `3`, а `-7 / 2` — `-3`. Знак
ненулевого остатка совпадает со знаком делимого, поэтому `-7 % 2` даёт `-1`.

Чтобы получить дробный результат из двух переменных типа `int`, преобразуйте оба операнда перед делением. Если
преобразовать результат уже после целочисленного деления, дробная часть будет потеряна.

```go
a, b := 7, 2
fractional := float64(a) / float64(b)
truncated := float64(a / b)
```

`fractional` равно `3.5`, а `truncated` равно `3`.

Целочисленное деление или вычисление остатка с нулевым делителем вызывает ошибку компиляции, если делитель — константа.
Если нулевое значение хранится в переменной, при выполнении возникает `panic`.

## Порядок вычислений

Операторы `*`, `/` и `%` имеют одинаковый приоритет и выполняются раньше `+` и `-`. Операторы одного приоритета
группируются слева направо. Например, `12 / 3 * 2` вычисляется как `(12 / 3) * 2` и даёт `8`.

Скобки позволяют явно задать группировку. Выражение `2 + 3 * 4` даёт `14`, а `(2 + 3) * 4` — `20`.

## Изменение переменной

Для обычной переменной запись `total += 5` равносильна `total = total + 5`. Для остальных операций есть `-=`, `*=`, `/=`
и `%=`.

`total++` увеличивает значение на единицу, а `total--` уменьшает. Это отдельные инструкции, поэтому запись
`result := total++` вызовет ошибку компиляции.

## Переполнение и точность

- Операции над беззнаковыми значениями фиксированной ширины отбрасывают старшие биты при переполнении. Складывая `1` с
  переменной `uint8` со значением `255`, получаем `0`. Для знаковых операций переполнение также имеет определённый
  результат и само по себе не вызывает `panic`. Константа должна помещаться в тип: `uint8(255 + 1)` не компилируется.
- `0.1 + 0.2 == 0.3` истинно для нетипизированных констант. Если `0.1` и `0.2` уже сохранены в переменных `float64`, их
  двоичное представление округлено и результат сложения может отличаться от ожидаемой десятичной дроби.
- Деление на нулевую константу недопустимо. Для деления на ноль во время выполнения у целых чисел спецификация
  гарантирует `panic`. Для чисел с плавающей точкой и комплексных чисел наличие `panic` зависит от реализации в рамках
  IEEE 754.
- При бинарной арифметике над типизированными числами типы должны совпадать. Нетипизированный литерал можно
  использовать, если он представим типом второго операнда. Например, `i + 1` допустимо при `i` типа `int64`.
