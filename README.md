# Урок 011. Циклы в Go

Цикл повторяет блок кода. В [hello.go](hello.go) показано, как выполнить заданное число итераций, повторять действия по
условию и перебрать элементы массива.

## Формы `for`

- `for i := 1; i <= 4; i++` — Объявляет счётчик один раз, проверяет условие перед каждой итерацией и увеличивает счётчик
  после неё.
- `for power < 10` — Проверяет условие перед каждой итерацией. В примере значение `power` удваивается внутри цикла.
- `for { ... }` — Повторяет тело без проверки условия. В примере цикл завершается через `break` после третьей итерации.
- `for index, value := range numbers` — Перебирает массив, возвращая индекс и значение каждого элемента.

В цикле со счётчиком `i <= 4` включает число `4`. Условие `i < 4` завершило бы цикл до этой итерации. Если проверка
ложна уже перед первым проходом, тело цикла с условием не выполнится ни разу.

## `break` и `continue`

В примерах `break` завершает ближайший цикл, а `continue` пропускает оставшуюся часть текущей итерации. Для цикла со
счётчиком после `continue` выполняется шаг вроде `i++`. В цикле с `range` Go переходит к следующему элементу.

В массиве `[2 5 8 11]` проверка `number%2 != 0` пропускает `5` и `11`. Поэтому к сумме прибавляются только `2` и `8`.
Запись `for _, number := range numbers` использует `_`, чтобы пропустить индекс.

## Что возвращает range

- **Массив, указатель на массив, срез** — Индекс и значение элемента. У присвоенной переменной элемента своё значение.
  Для записи в коллекцию используйте индекс.
- **Строка** — Смещение в байтах и `rune`. Некорректный UTF-8 даёт `U+FFFD` и продвижение на один байт.
- **Карта** — Ключ и значение. Порядок не гарантируется. Удалённый до посещения ключ пропускается, а добавленный может
  встретиться или нет.
- **Канал** — Принятое значение. Перебор завершается после закрытия канала и чтения всех оставшихся значений. Получение
  из `nil`-канала блокируется.
- **Целое `n`** — Значения от `0` до `n-1` начиная с Go 1.22. При `n <= 0` итераций нет.
- **Функция-итератор** — Значения, переданные функции `yield`, начиная с Go 1.23. Если цикл прерван, `yield` возвращает
  `false`, и повторно вызывать её уже нельзя.

Пустые массивы и строки, `nil`-срезы и `nil`-карты дают ноль итераций. Выражение справа от `range` обычно вычисляется
один раз перед циклом. Спецификация описывает исключение для перебора с одной переменной или без переменных, если сам
операнд или его `len` является константой.

## Переменные итераций и метки

Начиная с Go 1.22, объявленные в заголовке цикла переменные получают отдельные экземпляры на каждой итерации. Поэтому
замыкания в примере запоминают `0`, `1` и `2`. Если объявить `i` снаружи и писать `for i = range 3`, используется одна
переменная. Версию семантики для пакетов в модулях определяет директива `go` в `go.mod`.

Вложенные циклы можно завершать через `break label`. Вариант `continue label` переходит к следующей итерации указанного
внешнего цикла. Код урока использует `range` по числу и требует Go 1.22 или новее.
