# Урок 002. Переменные в Go

Ветка — `lesson-002-variables`. В файле [hello.go](hello.go) показано, как объявлять переменные с помощью `var` и `:=`.

| Запись | Что делает |
| --- | --- |
| `var name string` | Объявляет переменную с указанным типом и нулевым значением. Для `string` это `""`, для `int` — `0`, для `bool` — `false`. |
| `var name string = "Go"` | Объявляет переменную с указанным типом и начальным значением. |
| `var name = "Go"` | Объявляет переменную. Go выводит тип `string` из начального значения. |
| `name := "Go"` | Краткое объявление с выводом типа. Работает только внутри функций. |
| `name = "Golang"` | Присваивает новое значение уже объявленной переменной. |

Go чувствителен к регистру. В примере ниже `name` и `Name` — две разные переменные. После присваивания `name` содержит `"Язык Go"`, а `Name` содержит `"Golang"`.

```go
name := "Go"
Name := "Golang"
name = "Язык Go"
fmt.Println(name, Name)
```

Вызов `fmt.Println` тоже нужно писать с учётом регистра. Имя `Println` начинается с заглавной буквы, поэтому функция экспортируется из пакета `fmt` и доступна из `main`.

Запустите `go run hello.go`. Ожидаемый вывод:

```text
short short 2 short 3
Язык Go Golang
```
