# Урок 005. Арифметические операции в Go

Арифметическое выражение вычисляет значение по типам операндов. Например, `7 / 2` даёт целое `3`,
а `7.0 / 2.0` даёт `3.5`. У типизированных операндов бинарной операции типы должны совпадать.
Нетипизированная константа может принять тип второго операнда, если её значение в нём представимо.

| Оператор | Операция | Пример | Результат |
| --- | --- | --- | --- |
| `+` | Сложение | `7 + 2` | `9` |
| `-` | Вычитание | `7 - 2` | `5` |
| `*` | Умножение | `7 * 2` | `14` |
| `/` | Деление | `7 / 2` | `3` |
| `%` | Остаток от деления целых чисел | `7 % 2` | `1` |

## Деление и остаток

При делении целых чисел дробная часть отбрасывается в сторону нуля. Поэтому `7 / 2` даёт `3`, а `-7 / 2` — `-3`. Знак
ненулевого остатка совпадает со знаком делимого, поэтому `-7 % 2` даёт `-1`.

Чтобы получить дробный результат из двух переменных типа `int`, преобразуйте оба операнда перед делением. Если
преобразовать результат уже после целочисленного деления, дробная часть будет потеряна.

```go
a, b := 7, 2
fmt.Println(a / b)                   // 3
fmt.Println(float64(a) / float64(b)) // 3.5
fmt.Println(float64(a / b))          // 3
```

**Нулевой делитель.** Деление на нулевую константу и остаток с таким делителем вызывают ошибку компиляции.
Для целочисленной переменной со значением `0` эти операции вызывают панику во время выполнения.
Для деления чисел с плавающей точкой на ноль во время выполнения спецификация оставляет поведение
в пределах IEEE 754 на усмотрение реализации, в том числе вопрос о панике.

## Порядок вычислений

Операторы `*`, `/` и `%` имеют одинаковый приоритет и выполняются раньше `+` и `-`. Операторы одного приоритета
группируются слева направо. Например, `12 / 3 * 2` вычисляется как `(12 / 3) * 2` и даёт `8`.

Скобки позволяют явно задать группировку. Выражение `2 + 3 * 4` даёт `14`, а `(2 + 3) * 4` — `20`.

## Изменение переменной

Для обычной переменной запись `total += 5` равносильна `total = total + 5`. Для остальных операций есть `-=`, `*=`, `/=`
и `%=`.

`total++` увеличивает значение на единицу, а `total--` уменьшает. Это отдельные инструкции, поэтому запись
`result := total++` вызовет ошибку компиляции.

Порядок действий при составном присваивании разобран в [уроке 008][assignments].

## Переполнение и точность

При сложении значений `uint8` остаются младшие восемь бит результата. Число `256` имеет восемь нулевых
младших бит, поэтому результат сложения равен `0`. При работе с константой компилятор проверяет
представимость точного результата в целевом типе.

```go
var limit uint8 = 255
fmt.Println(limit + 1) // 0
// _ = uint8(255 + 1)  // Ошибка компиляции. 256 выходит за диапазон uint8.
```

Знаковое переполнение целых чисел тоже имеет определённый результат. Например, деление минимального
`int8` (`-128`) на `-1` даёт то же значение `-128` и остаток `0`.

Нетипизированные константы сохраняют точные значения. У `float64` значения `0.1` и `0.2` округляются
при сохранении в переменные. Округлённая сумма отличается от представления `0.3` в `float64`.

```go
x, y := 0.1, 0.2
fmt.Println(0.1 + 0.2 == 0.3) // true
fmt.Println(x + y == 0.3)     // false
```
