# Урок 006. Условные выражения в Go

В [hello.go](hello.go) сравниваем значения, объединяем проверки и передаём результат в `if`. Условное выражение даёт значение типа `bool`: `true` или `false`.

## Сравнения

| Оператор | Проверка | Пример | Результат |
| --- | --- | --- | --- |
| `==` | Равенство | `7 == 2` | `false` |
| `!=` | Неравенство | `7 != 2` | `true` |
| `<` | Строго меньше | `7 < 2` | `false` |
| `<=` | Меньше или равно | `7 <= 7` | `true` |
| `>` | Строго больше | `7 > 2` | `true` |
| `>=` | Больше или равно | `2 >= 7` | `false` |

Порядковые сравнения применимы к целым числам, числам с плавающей точкой и строкам. Равенство и неравенство подходят и для логических значений.

## Логические операторы

| Оператор | Когда выражение истинно |
| --- | --- |
| `a && b` | Оба условия истинны. |
| `a || b` | Хотя бы одно условие истинно. |
| `!a` | Условие `a` ложно. |

Среди логических операторов самый высокий приоритет у `!`, затем идёт `&&`, затем `||`. Скобки помогают явно показать, какие проверки составляют одно условие.

Операторы `&&` и `||` вычисляют левую часть первой. Если она уже определяет результат, правая часть пропускается. Для `&&` это происходит при `false`, для `||` — при `true`. Поэтому выражение `divisor != 0 && a/divisor > 2` безопасно и при нулевом делителе, если `divisor` — переменная.

## Условие в `if`

`if` выполняет первый блок при `true`, а блок `else` — при `false`. В примере право войти проверяется выражением `isAdult && hasTicket`. Возраст подходит, но значение `hasTicket` равно `false`, поэтому программа выводит «Вход закрыт».

## Запуск

Выполните `go run hello.go` из каталога урока.

```text
7 == 2 = false
7 != 2 = true
7 < 2 = false
7 <= 7 = true
7 > 2 = true
2 >= 7 = false
isAdult && hasTicket = false
isAdult || hasTicket = true
!hasTicket = true
Безопасная проверка = false
Вход закрыт
```
