# Урок 006. Условные выражения в Go

В [hello.go](hello.go) сравниваем значения, объединяем проверки и передаём результат в `if`. Условие имеет логическое
значение `true` или `false`. Результат сравнения по правилам языка является нетипизированным логическим значением и при
кратком объявлении получает тип `bool`.

## Сравнения

| Оператор | Проверка | Пример | Результат |
| --- | --- | --- | --- |
| `==` | Равенство | `7 == 2` | `false` |
| `!=` | Неравенство | `7 != 2` | `true` |
| `<` | Строго меньше | `7 < 2` | `false` |
| `<=` | Меньше или равно | `7 <= 7` | `true` |
| `>` | Строго больше | `7 > 2` | `true` |
| `>=` | Больше или равно | `2 >= 7` | `false` |

Порядковые сравнения применимы к целым числам, числам с плавающей точкой и строкам. Равенство и неравенство подходят и
для логических значений.

## Логические операторы

| Оператор | Когда выражение истинно |
| --- | --- |
| `a && b` | Оба условия истинны. |
| `a || b` | Хотя бы одно условие истинно. |
| `!a` | Условие `a` ложно. |

Среди логических операторов самый высокий приоритет у `!`, затем идёт `&&`, затем `||`. Скобки помогают явно показать,
какие проверки составляют одно условие.

Операторы `&&` и `||` вычисляют левую часть первой. Если она уже определяет результат, правая часть пропускается. Для
`&&` это происходит при `false`, для `||` — при `true`. Поэтому выражение `divisor != 0 && a/divisor > 2` безопасно и
при нулевом делителе, если `divisor` — переменная.

## Условие в `if`

`if` выполняет первый блок при `true`, а блок `else` — при `false`. В примере право войти проверяется выражением
`isAdult && hasTicket`. Возраст подходит, но значение `hasTicket` равно `false`, поэтому выполняется блок `else`.

## Сравнимость и пограничные случаи

- Для `==` и `!=` операнды должны быть сравнимы, а один операнд должен быть присваиваем типу другого. Например, две
  переменные типов `int` и `int64` требуют явного преобразования. Составные выражения записывают как
  `low < value && value < high`, поскольку цепочка `low < value < high` недопустима.
- Строки упорядочиваются лексикографически по байтам. Это правило подходит для точного сравнения и не учитывает языковые
  правила сортировки. У комплексных чисел и `bool` есть равенство, но нет операторов порядка.
- Массив сравним, если сравним тип его элементов. Структура сравнима, если сравнимы все её поля. Срезы, карты и функции
  можно сравнить с `nil`. Для равенства содержимого коллекций нужны правила для их элементов.
- Интерфейс равен `nil`, когда отсутствуют динамический тип и значение. Интерфейс с динамическим типом `*int` и
  значением `nil` не равен `nil`. Сравнение двух интерфейсов с одним и тем же несравнимым динамическим типом вызывает
  `panic`, например, при сравнении двух интерфейсных значений со срезами.
- `NaN` не равен самому себе. Проверку выполняют через `math.IsNaN`. `&&` и `||` работают с логическими операндами и
  вычисляют правую часть только при необходимости.
