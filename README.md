# Урок 012. Функции и их параметры в Go

В [hello.go](hello.go) показано, как объявлять и вызывать функции, передавать аргументы и получать результаты.

## Объявление и вызов

```go
func plus(a, b int) int {
    return a + b
}
```

- `func` начинает объявление функции, а `plus` — её имя.
- `a` и `b` — параметры. Запись `a, b int` задаёт тип `int` обоим параметрам.
- Последний `int` задаёт тип результата, а `return` возвращает значение.
- В вызове `plus(3, 4)` числа `3` и `4` — аргументы. Вызов возвращает `7`.

Сигнатуру задают типы параметров и результатов. Например, у `plus` тип функции `func(int, int) int`. Если функция ничего
не возвращает, тип результата опускают, как в `func saySomething(message string)`. Результат одного вызова можно
передать в другой. Так работает `saySomething(greeting("Анна"))`.

Если результатов несколько, их типы перечисляют в скобках. Функция `swap(a, b int) (int, int)` возвращает аргументы в
обратном порядке. Вызов `left, right := swap(1, 2)` записывает `2` в `left` и `1` в `right`.

## Именованные возвращаемые результаты

Результатам можно дать имена в объявлении функции. Внутри функции они доступны как переменные и изначально имеют нулевые
значения своего типа. У `area` и `perimeter` начальное значение `0`.

```go
func rectangle(width, height int) (area, perimeter int) {
    area = width * height
    perimeter = 2 * (width + height)
    return
}
```

`return` без выражений возвращает текущие значения в порядке объявления результатов. Здесь можно также написать
`return area, perimeter`. Вызов `rectangle(3, 4)` возвращает площадь `12` и периметр `14`.

## Передача по значению

Go передаёт аргументы по значению. Когда вызывается `addTwenty(a)`, параметр `x` получает копию числа `8`. После
`x += 20` внутри функции `x` равен `28`, а в переменной `a` у вызывающего кода по-прежнему хранится `8`.

## Переменное число аргументов

Параметр вида `numbers ...int` может стоять только последним. Он принимает любое количество аргументов типа `int`,
включая ноль. Внутри функции `numbers` имеет тип `[]int`, поэтому его элементы можно перебрать через `range`.

| Вызов | Результат |
| --- | --- |
| `sum(1, 2, 3)` | `6` |
| `sum()` | `0` |
| `sum(values...)` при `values := []int{4, 5}` | `9` |

Троеточие после `values` передаёт элементы среза в вариативный параметр.

## Подробности для собеседования

- Имена параметров и результатов помогают читать объявление. Идентичность типов функций определяется порядком и типами
  параметров и результатов, а также наличием вариативного параметра. `func(...int)` и `func([]int)` — разные типы.
  Функцию можно передать аргументом или сохранить в переменной. Вызов функционального значения `nil` вызывает `panic`.
- При передаче среза копируется значение среза, но элементы могут оставаться в общей памяти. Поэтому изменение элемента
  видно вызывающему коду. Аналогично копирование указателя сохраняет адрес исходного объекта.
- У вариативной функции `numbers` равен `nil`, если не передан ни один аргумент для этого параметра. Отдельные аргументы
  собираются в новый срез. Вызов `setFirst(7, values...)` передаёт существующий срез напрямую, и функция меняет его
  первый элемент. Для одного вариативного параметра нельзя смешивать отдельные значения и разворачивание среза.
- Именованные результаты являются локальными переменными с нулевыми значениями. При явном `return 10` значение `10`
  сначала записывается в именованный результат. Затем выполняется `defer`. Если отложенное замыкание увеличивает эту
  переменную, вызывающий код получает итоговое значение `11`.
- Вложенное объявление может затенить имя возвращаемого результата. Компилятор вправе отклонить `return` без выражений в
  точке, где результат затенён. Явный `return value` показывает, какое значение возвращается в этой ветке.
