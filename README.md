# Урок 006. Условные выражения в Go

Условие в Go выражается логическим значением. Сравнение проверяет отношение между двумя значениями,
а логические операторы связывают несколько проверок. Например, в `matches := 7 == 2` результат
сравнения является нетипизированным логическим значением, поэтому переменная получает тип `bool`.

## Операторы сравнения

| Оператор | Проверка | Пример и результат |
| --- | --- | --- |
| `==` | Равенство | `7 == 2` даёт `false` |
| `!=` | Неравенство | `7 != 2` даёт `true` |
| `<`, `<=` | Меньше, меньше или равно | `2 < 7` и `7 <= 7` дают `true` |
| `>`, `>=` | Больше, больше или равно | `7 > 2` даёт `true`, `2 >= 7` даёт `false` |

При сравнении хотя бы один операнд должен быть присваиваем типу другого. Например, две переменные типа
`int` и `int64` можно сравнить после явного преобразования одного операнда.

## Какие типы можно сравнивать

| Типы | Допустимые сравнения |
| --- | --- |
| Целые числа, числа с плавающей точкой, строки | Равенство и порядок |
| Логические и комплексные значения, указатели, каналы, интерфейсы | Равенство и неравенство |
| Массивы и структуры | Равенство и неравенство, если сравнимы типы всех элементов или полей |
| Срезы, карты и функции | Равенство и неравенство с `nil` |

У массивов Go проверяет элементы по индексам, а у структур — соответствующие поля с именами, отличными от `_`.
Указатели сравниваются по тому, указывают ли они на одну переменную. Указатели на разные переменные
нулевого размера тоже могут оказаться равны. Каналы равны, если обозначают один канал.
Два указателя или два канала также равны, если оба значения равны `nil`.

Строки сравниваются **побайтово**. Первый различающийся байт определяет порядок. Если одна строка
совпадает с началом другой, короче расположена раньше.

```go
fmt.Println("Go" < "Go!") // true
fmt.Println("Go" < "go")  // true, байт G меньше байта g.
```

Сравнения чисел с плавающей точкой следуют IEEE 754. У `NaN` равенство с любым значением, включая
самого себя, даёт `false`. Проверить `NaN` можно через `math.IsNaN`.

```go
nan := math.NaN()
fmt.Println(nan == nan, math.IsNaN(nan)) // false true
```

### Интерфейсы и динамический тип

Интерфейсные значения равны, если оба равны `nil` либо если совпадают их динамические типы и равны их
динамические значения. Интерфейс, которому присвоили нулевой указатель, хранит тип `*int`, поэтому
сравнение интерфейса с `nil` даёт `false`.

```go
var pointer *int
var boxed any = pointer
fmt.Println(pointer == nil, boxed == nil) // true false
```

Если динамические типы двух интерфейсов совпадают, Go пытается сравнить содержащиеся в них значения.
Несравнимый динамический тип в этом случае вызывает панику. При прямом сравнении двух срезов
компилятор видит несравнимые типы заранее и отклоняет выражение.

```go
a, b := []int{1}, []int{1}
// fmt.Println(a == b)           // Ошибка компиляции. Два среза несравнимы.
// fmt.Println(any(a) == any(b))  // Паника. Общий динамический тип []int несравним.
```

## Логические операторы

| Оператор | Когда выражение истинно |
| --- | --- |
| `a && b` | Оба условия истинны |
| `a \|\| b` | Хотя бы одно условие истинно |
| `!a` | Условие `a` ложно |

Сначала вычисляется левая часть `&&` или `||`. Если она уже определяет результат, правая часть
пропускается. Это **короткое замыкание**. Для `&&` достаточно левого `false`, а для `||` достаточно
левого `true`. Поэтому в обоих выражениях ниже деление пропускается.

```go
divisor := 0
fmt.Println(divisor != 0 && 7/divisor > 2) // false
fmt.Println(divisor == 0 || 7/divisor > 2) // true
```

У логического отрицания `!` выше приоритет, чем у `&&`, а у `&&` выше, чем у `||`.
Для проверки диапазона используйте `low < value && value < high`. Запись `low < value < high` отклоняется,
потому что результат первого сравнения является логическим значением и для него оператор `<` недоступен.

Условие можно передать в `if` напрямую или сохранить в переменной `bool`. Синтаксис ветвления разобран
в [уроке 010][conditionals]. Запустите [hello.go](hello.go) командой `go run hello.go`.
