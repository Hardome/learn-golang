# Изучаем Go

Учебный проект по Go. Каждый урок находится в отдельной ветке. 
Имена веток имеют формат `lesson-NNN-topic`, где `NNN` — трёхзначный номер урока, а `topic` — короткое название темы на английском через дефисы.

## Урок 001. Hello, world!

Ветка — `lesson-001-hello-world`. Программа в файле [hello.go](hello.go) выводит `Hello, world!`. 
Пакет `main` обозначает исполняемую программу, функция `main` служит точкой входа, а `fmt.Println` печатает строку и переводит курсор на новую строку.

### Команды

Установите Go и выполняйте команды из каталога с файлом `hello.go`.

| Команда | Что делает |
| --- | --- |
| `go version` | Показывает установленную версию Go, операционную систему и архитектуру. |
| `go run hello.go` | Компилирует и сразу запускает программу. В каталоге проекта исполняемый файл не появляется. |
| `go build hello.go` | Собирает исполняемый файл в текущем каталоге. На Windows это `hello.exe`, на Linux и macOS — `hello`. |

После сборки запустите файл командой `./hello` на Linux или macOS либо `.\hello.exe` в PowerShell. Ожидаемый вывод — `Hello, world!`.

## Урок 002. Переменные

Ветка — `lesson-002-variables`. В файле [hello.go](hello.go) показано, как объявлять переменные с помощью `var` и `:=`.

| Запись | Что делает |
| --- | --- |
| `var name string` | Объявляет переменную с указанным типом и нулевым значением. Для `string` это `""`, для `int` — `0`, для `bool` — `false`. |
| `var name string = "Go"` | Объявляет переменную с указанным типом и начальным значением. |
| `var name = "Go"` | Объявляет переменную. Go выводит тип `string` из начального значения. |
| `name := "Go"` | Краткое объявление с выводом типа. Работает только внутри функций. |
| `name = "Golang"` | Присваивает новое значение уже объявленной переменной. |

Go чувствителен к регистру. В примере ниже `name` и `Name` — две разные переменные. После присваивания `name` содержит `"Язык Go"`, а `Name` содержит `"Golang"`.

```go
name := "Go"
Name := "Golang"
name = "Язык Go"
fmt.Println(name, Name)
```

Вызов `fmt.Println` тоже нужно писать с учётом регистра. Имя `Println` начинается с заглавной буквы, поэтому функция экспортируется из пакета `fmt` и доступна из `main`.

Запустите `go run hello.go`. Ожидаемый вывод:

```text
short short 2 short 3
Язык Go Golang
```
