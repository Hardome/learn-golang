# Урок 009. Массивы в Go

Массив хранит фиксированное количество элементов одного типа. В записи `[5]int` число `5` входит в тип, поэтому `[5]int` и `[4]int` — разные типы. В [hello.go](hello.go) показано, как объявлять, читать, сравнивать, копировать и перебирать массивы.

## Объявление и заполнение

| Запись | Что получается |
| --- | --- |
| `var numbers [5]int` | Пять нулей. Каждый элемент получает нулевое значение своего типа. |
| `[5]int{1, 2, 3, 4, 5}` | Пять заданных целых чисел. |
| `[5]int{1}` | Массив `[1 0 0 0 0]`. Пропущенные элементы получают нулевые значения. |
| `[...]int{1}` | Массив типа `[1]int` с единственным элементом. |
| `[...]int{3: 7}` | Массив типа `[4]int`. Значение `7` находится по индексу `3`, длина равна `4`. |

В непустом литерале с `[...]` длина равна наибольшему индексу элемента плюс один. Если индексы опущены, элементы идут с нулевой позиции подряд. Например, `[...]int{2, 4, 6}` имеет тип `[3]int`.

## Индексы и перебор

`len(values)` возвращает число элементов. `values[0]` читает первый элемент, а `values[len(values)-1]` — последний элемент непустого массива. Запись `values[0] = 99` меняет первый элемент.

Для массива длины `5` допустимы индексы от `0` до `4`. Индекс-константа за пределами массива вызывает ошибку компиляции. Если индекс вычисляется во время выполнения и выходит за границы, возникает `panic`.

Цикл `for index, value := range values` даёт индекс и значение каждого элемента. В примере из программы `for _, value := range values` пропускает индекс и суммирует значения.

## Сравнение и копирование

Массивы одного типа можно сравнить через `==`, если их элементы допускают сравнение. Массивы равны, когда совпадают элементы на всех позициях. Например, `[4]int{3, 4, 5}` и `[4]int{3, 4, 5, 0}` равны, поскольку пропущенный элемент получает значение `0`.

При присваивании копируются все элементы массива. После `copied := values` запись `copied[0] = 99` меняет первый элемент копии, а в `values[0]` по-прежнему хранится `1`.

## Копии, адресуемость и пустые массивы

- Длина — неотрицательная константа, представимая типом `int`. Массив `[0]int{}` допустим, его длина и ёмкость равны нулю. Многомерный массив строится из вложенных массивов, например `[2][3]int`.
- Присваивание и передача массива в функцию копируют значения элементов. У массива указателей копируются сами указатели. Такой массив может по-прежнему обращаться к тем же объектам. Если нужно изменить элементы исходного массива, передайте указатель на массив или срез.
- У адресуемого массива выражение `values[:]` создаёт срез, который использует массив как хранилище. Изменение элемента такого среза видно через массив. Сам массив сохраняет фиксированную длину.
- При переборе значения массива с двумя переменными итерации `range` работает со значением, вычисленным перед циклом. В примере изменение `sample[1]` даёт массив `[1 20 3]`, а перебор складывает исходные `1 + 2 + 3`. Перебор указателя на массив с чтением элементов использует исходный массив.
- Даже массив длины ноль сравним только при сравнимом типе элемента. Например, `[0]int` сравним, а `[0][]int` — нет. Вложенные массивы сравниваются рекурсивно по своим элементам.
