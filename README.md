# Урок 004. Константы в Go

В [hello.go](hello.go) показано, как объявлять константы с помощью `const`. Их значения известны во время компиляции. Константу объявляют сразу со значением. Попытка изменить это значение вызывает ошибку компиляции. Объявлять константы можно как на уровне пакета, так и внутри функции.

## Объявление и тип

| Запись | Что объявляет |
| --- | --- |
| `const appName string = "Go"` | Типизированную строковую константу. |
| `const defaultRetries = 3` | Нетипизированную целочисленную константу. |
| `const secondsPerHour = 60 * secondsPerMinute` | Константу, вычисленную из литерала и другой константы. При `secondsPerMinute = 60` получится `3600`. |

Константы бывают логическими, строковыми и числовыми. При присваивании нетипизированной константы переменной Go проверяет, помещается ли значение в тип переменной. Например, `3` подходит для `uint8` и `int64`, а `256` выходит за пределы диапазона `uint8`.

```go
const defaultRetries = 3
var retries8 uint8 = defaultRetries
var retries64 int64 = defaultRetries
// const retries = retries8 // Ошибка компиляции: retries8 — переменная.
```

## Блок `const` и `iota`

В блоке `const (...)` первая строка объявления содержит выражение. Если ниже его опустить, Go повторит список выражений и указанный тип из ближайшей предыдущей строки, где они были записаны. Поэтому `mediumLimit` получает `int(1)`, а `maxLimit` — `int(3)`.

```go
const (
    smallLimit int = 1
    mediumLimit
    largeLimit int = 3
    maxLimit
)
```

`iota` — индекс объявления внутри блока `const`. Он начинается с `0` в каждом блоке и увеличивается на единицу для каждого следующего объявления. Блок из программы повторяет выражение `1 << iota`. Оператор `<<` сдвигает единичный бит влево, поэтому получаются значения `1`, `2` и `4`.

```go
const (
    readMask = 1 << iota // 1 << 0 = 1
    writeMask           // 1 << 1 = 2
    executeMask         // 1 << 2 = 4
)
```
