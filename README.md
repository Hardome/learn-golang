# Урок 011. Циклы в Go

Цикл повторяет блок кода.

В [hello.go](hello.go) показаны циклы со счётчиком, с условием, без условия и с перебором элементов через `range`.

## Формы `for`

- `for i := 1; i <= 4; i++` — Объявляет счётчик один раз, проверяет условие перед каждой итерацией и увеличивает счётчик
  после неё.
- `for power < 10` — Проверяет условие перед каждой итерацией. В примере значение `power` удваивается внутри цикла.
- `for { ... }` — Повторяет тело без проверки условия. В примере цикл завершается через `break` после третьей итерации.
- `for index, value := range numbers` — Перебирает массив, возвращая индекс и значение каждого элемента.

Условие `i <= 4` включает итерацию с `i == 4`. Условие `i < 4` завершило бы цикл до неё.

Если условие ложно при первой проверке, тело цикла не выполняется ни разу.

## `break` и `continue`

### `break`

В примере `break` завершает ближайший цикл.

`break label` завершает внешний цикл с указанной меткой.

### `continue`

`continue` пропускает оставшуюся часть текущей итерации. В примере проверка `number%2 != 0` пропускает нечётные `5` и
`11`, поэтому к сумме прибавляются только `2` и `8`.

В цикле со счётчиком после `continue` выполняется шаг вроде `i++`.

В цикле с `range` после `continue` Go переходит к следующему элементу.

`continue label` переходит к следующей итерации внешнего цикла с указанной меткой.

## Перебор через `range`

### Массивы, указатели на массивы и срезы

`range` даёт индекс и значение элемента.

Запись `for _, number := range numbers` пропускает индекс.

Переменная итерации получает значение элемента. Чтобы записать новое значение в коллекцию, используйте индекс.

### Строки

`range` даёт смещение в байтах и значение типа `rune`.

При некорректном UTF-8 `range` выдаёт `U+FFFD` и продвигается на один байт.

### Карты

`range` даёт ключ и значение.

Порядок перебора не гарантируется.

Ключ, удалённый до посещения, пропускается.

Ключ, добавленный во время перебора, может встретиться в этом же цикле.

### Каналы

`range` даёт значения, принятые из канала.

Перебор завершается после закрытия канала и чтения всех оставшихся значений.

Получение из `nil`-канала блокируется.

### Целые числа

Начиная с Go 1.22, `range n` даёт значения от `0` до `n-1`.

При `n <= 0` итераций нет.

### Функции-итераторы

Начиная с Go 1.23, `range` перебирает значения, переданные функции `yield`.

Если цикл прерван, `yield` возвращает `false`. После этого вызывать её повторно нельзя.

### Вычисление выражения `range`

Выражение справа от `range` обычно вычисляется один раз перед циклом.

При одной переменной итерации или без переменных выражение пропускается, если оно само или его `len` — константа.

### Перебор без итераций

Пустые массивы и строки, `nil`-срезы и `nil`-карты дают ноль итераций.

## Переменные итераций

Начиная с Go 1.22, объявленные в заголовке цикла переменные получают отдельные экземпляры на каждой итерации. Поэтому
замыкания в примере запоминают `0`, `1` и `2`.

Если объявить `i` снаружи и писать `for i = range 3`, все итерации используют одну переменную.

Версию семантики для пакетов в модулях определяет директива `go` в `go.mod`.
